# 人界

> 一个由九大种族、八域宇宙与历代大帝谱系构成的修仙世界；人界之外另有仙界，三清以上的历史属于仙界篇。（世界名为暂定名，取自原始便签的"人界篇"。）

## 世界速览

人界是一片以"修炼"为绝对主轴的宇宙。生灵从凡人起步，沿练气、筑基直至问仙的漫长境界阶梯向上攀登；进入归一之后，通往至高境界的道路开始分化：有人继续沿半道、绝巅探索自身大道，最终可能成就道尊；也有人在半道以下参与帝路争锋、争得天道本源而证道大帝。大帝与道尊都是宇宙中最强的存在，正常寿命约二百五十万年。大帝交替由天道本源驱动：通常当世无帝时，天道才会释放一缕本源，开启持续上万年的帝路争锋，最终诞生新的大帝，如此轮回。

宇宙分为八域：帝落域历史最悠久、实力最强劲；古域是龙族的根基；九星秘境域是灵族的主要根据地。九大种族——人族、妖族、龙族、天族、灵族、神族、魔族、鬼族、冥族——共居于八域。当今宇宙最强大的势力是归一联盟，集合了绝大多数归一境强者，存在数百万年，长期承担近似宇宙公共秩序中枢的角色，是宇宙顶层强者默认参与的政治体系；其下由"五会"（李族、神武族、古夜族、帝兽族、星族）实际主导话语权。

历史上，太初大帝终结了洪荒时代十大神兽的统治，开启了神化时代；此后历经拓荒、太古、天武、开盛诸时代，**公开正史共记录六十一尊帝级存在——五十三位大帝与八位道尊**。此外，长生尊属于被正史完全遗漏的隐秘大帝，不计入这六十一位公开谱系，因此实际已知帝级存在至少为六十二位。每位真正的大帝都拥有一件本命帝兵、每位道尊拥有一件本命道兵，并在历史中留下不同程度的功法、兵器、势力、遗迹与传说。太初古矿、堕仙界、九龙谷等九大禁区是宇宙中最危险也最神秘的历史遗产。而长生尊——一位从洪荒时代活到今日、以吞噬他人寿命延续自身的暗处存在——始终游离于所有规则与势力之外。

## 正式设定

### 天地与宇宙

人界之外存在仙界。三清时代的往事属于仙界篇：元始天尊与道德天尊大战，打得仙界天地破碎、大道法则崩坏消散；灵宝天尊劝架后，元始天尊化宙宇为两界、分隔天人之界，自己前往九界深渊镇守大道法则，不可擅离；道德天尊化人界天道、重塑法则，随即兵解，身化灵气、魂化大道，使人界复苏生机；轮回天尊为镇压乱世创立天庭，立下九天十地、九大天尊、十大界域与三十六位地尊；灵宝天尊带弟子前往自辟的灵宝天界，不与仙界接壤，万世不出。三清往上的历史属于仙界篇，人界正文从洪荒时代开始。

**八域**：

“域”是宇宙级地理单位，并非单一大陆或单一星球。每一域都包含数量庞大的星辰、生命世界、秘境与无人虚空；跨域旅行对普通修士而言极其困难，真正稳定的跨域通行依赖大型星门、远距离传送阵或高阶强者横渡虚空。

| 域名 | 整体定位 | 主要特征 |
| --- | --- | --- |
| 化心域 | 中等强域 | 星辰分布疏密不均，古老心神、幻术与神魂类遗迹较多；无尽深渊位于此域，使其长期存在大量危险航道与封锁区。 |
| 九星秘境域 | 较强 | 由九片巨型星群与中央灵能漩涡构成，灵族主要根据地；灵能资源极盛，但空间秘境与灵潮暴动频繁。 |
| 帝落域 | 八域之首 | 历史最悠久、顶尖势力与帝级遗迹最密集，帝星是其政治与修炼中心；太初古矿、不灭凤巢、葬神墓地三大禁区均位于此域。 |
| 天朝域 | 新兴强域 | 新王朝、新宗门与跨族势力更替最快，旧秩序较弱，因此扩张、兼并与崛起机会最多；魔骨血海是最大的长期威胁。 |
| 划凡域 | 相对弱小 | 高阶灵脉较少，但凡人世界与低阶修士数量庞大，是人口、基础物资与商路最密集的区域之一；大势力对基层世界的直接控制反而较弱。 |
| 飞仙域 | 老牌强域 | 古宗、遗迹和飞升传说众多，整体秩序稳定，老牌势力之间边界清晰；堕仙界使其成为研究帝法与禁区遗产的重要区域。 |
| 楚域 | 中等强域 | 历史上多次遭遇空间破碎与大战余波，遗留大量断裂星路、鬼灵与时空异常；九幽仙宫是其最危险的核心禁区。 |
| 古域 | 老牌强域 | 龙族根基所在，龙脉、古星与血脉祖地极多；五大龙族支脉长期共同维持秩序，对外来势力进入核心区域限制最严。 |

八域没有统一的凡俗政权。归一联盟负责跨域层面的高阶秩序，而绝大多数星辰、王朝、宗门和家族仍拥有高度自治权，因此“宇宙存在最强公共秩序”与“地方长期战乱、宗门争霸”可以同时成立。

**帝星与帝落域五洲**：帝星是帝落域最重要的超级生命古星，也是整个帝落域的势力核心。现有资料明确列出的核心区域为五洲；“五洲”是历史沿用的地理称呼，不代表帝星只有五块陆地，也不代表帝落域只有帝星一处文明中心。为统一写法，五处均使用“洲”。

- **南淞洲**：宋王府、石林族、鬼魅族、南妖族、普华天龙寺♢、万仙阁♢、重阳宗、古罗寺、碧螺天、复光宗、古仙神朝♢、南海蛟族
- **西龙洲**：古佛宗♢、青山派、沙龙族、古魔宗、五色神朝♢、西墨族、普罗神朝、盗月宗、满阳楼、九部古妖族、盘龙族、焦山派、白朴寺♢、古龙寺♢、阳神教
- **北烟洲**：万盛天国、化天紊尊族♢、长明派、古神族♢、生死天、北海蛟族♢、仙乐楼、万妖阁♢、神牛族、古鹏族♢、黑龙族、炎王教、封神宗
- **东华洲**：飞仙教♢、尸谷♢、毒宗、绝情谷、浩气宗、九岭部、天山峨、清墨教、阴宗、邪龙族♢、古泉池、凤羽教、灵族支脉♢、兽谷、极天妖族♢
- **中洲**：万妖武殿♢、神时阁♢、古藏♢、道一宗♢、万妖宗♢、帝院♢、始族♢、神组♢、星族♢、天机阁♢、李族♢

♢只代表“顶尖势力”层级，不代表这些势力彼此同盟，也不代表未标♢者必然弱小；某些势力可能因帝兵、半道老祖、历史盟约等特殊底蕴拥有超出常规评级的威慑力。

**九大禁区**（括号内为所处域）：太初古矿（帝落域）、堕仙界（飞仙域）、九龙谷（古域）、不灭凤巢（帝落域）、无道死地（九星秘境域）、九幽仙宫（楚域）、无尽深渊（化心域）、魔骨血海（天朝域）、葬神墓地（帝落域）。

“禁区”是后世对最高危险区的统称，并不意味着九处拥有同一种起源：有的是大帝主动开辟的试炼地，有的是远古遗留的生命禁地，有的是大战、封印或异常法则长期累积后形成的灾区。禁区也并非绝对无人能够进入，而是内部存在足以杀死归一乃至威胁半道强者的区域。

太初古矿由太初大帝以诸禁区收获开辟，最初存放【太初鼎】、《太初法》与大量珍宝，太初道文使部分宝物和环境形成长期循环，本意是为后人留下试炼与传承之地。后来长生尊曾从太初古矿取得并使用【太初鼎】；公开世界并不知道这一段完整历史，因此很多古籍仍把【太初鼎】记作“沉睡于太初古矿深处”。真实状态下，【太初鼎】已不应再被视为确定存放在古矿中的宝物。

斗天大帝后来把斗天九法分别布入九大禁区，使每一处禁区都对应九法中的一部分传承或考验。九大禁区目前可统一理解如下：

| 禁区 | 核心特征 | 已知关键遗产 / 风险 |
| --- | --- | --- |
| 太初古矿 | 人工开辟的帝级试炼地，内部层层空间与太初道文长期运转 | 《太初法》、大量历代遗物、时间裂隙；【太初鼎】曾存于此，但真实状态已被长生尊取走 |
| 堕仙界 | 斗天大帝亲自开辟，法则极端混乱，常出现“功法互斥”与大道压制 | 斗天九法的重要总纲线索、帝级战斗遗痕 |
| 九龙谷 | 古域龙族最古老的死亡与蜕变之地之一，空间被多次帝级大战改变 | 龙族古血、逆鳞、龙魂残响；部分区域在赤凤道尊与天鹏大帝之战后永久扭曲 |
| 不灭凤巢 | 凤凰一脉洪荒祖地，涅槃之火与死亡气息同时存在 | 凤凰遗血、涅槃残火；进入者可能被不灭火焚身，也可能被强行拖入失控涅槃 |
| 无道死地 | 法则感知会被持续削弱，越深入越难借用天地大道 | 古仙大帝所化【葬仙链】镇锁核心；适合磨炼自身大道，也极易造成永久道伤 |
| 九幽仙宫 | 鬼族与时空异常最集中的古老宫域，内部空间层级不断变化 | 上古鬼皇遗迹、时空碎片；部分通道会把进入者送到完全不同的年代残影或空间夹层 |
| 无尽深渊 | 神凰大帝开辟的极端不灭试炼地，封存大量洪荒遗种 | 十颗不灭丹、《不灭经》；深层洪荒生物足以威胁归一乃至半道 |
| 魔骨血海 | 无数古魔尸骨、血气与雷劫残力长期沉积形成 | 古魔残骸、魔道淬体资源、失控血灵；古魔大帝与多位魔族强者均曾在此修炼 |
| 葬神墓地 | 帝落域最古老的死亡禁区之一，埋藏大量无法确认身份的神尸与古棺 | 神冥道尊、时空大帝均与此地有关；地藏大帝最后一次公开出现也在其最深处 |

禁区不是“进去必死”的地图边界，而是层级极深的危险生态。外围可能长期存在冒险者、宗门据点和资源交易，中层足以杀死普通高阶修士，核心区则通常只有归一以上强者才有资格尝试。这样既保留禁区威慑力，也允许它们真正参与日常剧情，而不是只能作为背景名词。

### 修炼体系

每个境界通常分为初期、中期、后期、圆满。

| 筑基 | 在体内建立稳定修炼根基，使灵气循环从“借外界”转为“自身可持续运转”；筑基质量会长期影响后续上限 |

**修炼共通规则**：

- **练气三途**：练体、练心、练魂是练气阶段最常见的三种入门方向，而不是三个永远互斥的职业。大多数修士会选择一途为主、另外两途为辅；越到高境界，肉身、神魂、心境三者越难彻底割裂。
- **寿命含义**：表中寿命是无重大伤势、无特殊血脉与延寿手段时的通常自然上限，不代表一定能够活到该年限。封印、沉眠可以大幅降低生命气息流失，但不会凭空增加境界，也不能无限规避天道对年龄与生命本质的判断。
- **越境原则**：低境修士可以依靠体质、功法、秘术、阵法、帝兵等越境战斗，但境界越高，越境难度越大。归一以上的差距主要来自大道完整度，仅靠普通资源堆积很难抹平。
- **帝路年龄**：帝路“十万岁以下”以天道识别的当前完整生命年轮为准。长期封印与普通沉眠不能把年龄重新归零，因此不能通过自封百万年后再参加帝路来绕过限制。只有极少数真正完成“上一生命彻底终结、以新生命重新诞生”的涅槃或再生，才会形成新的生命年轮；这类重生通常伴随旧肉身、修为乃至大量记忆丧失，不能等同于低成本续命。
- **半道以上不得争帝**：半道及绝巅修士的大道已经高度自成，与代表人界天道权柄的天道本源存在根本排斥，因此正常情况下不能参与帝路争锋；若放弃自身道路重新争帝，等同于自毁原有根基，现有历史中没有可稳定复制的成功方法。

**归一三阶段**：归一本质是一个大境界的三种不同阶段。化简相当于最初始的状态，使各种法则化简融入自身、融会贯通；合一可使各种法则融入自己的大道，实力提升数倍，明显强于化简；无瑕字面意思即所感悟的大道没有任何瑕疵，是最极致的归一阶段，在极限程度上可以与半道级强者短暂交手。

**半道**：最强之下的存在。古往今来不会同时存在超过五位。大多数半道将自身封印，避免生命气息流失，从而可以镇守大势力核心区域数百万年；所以除非所在势力遭遇灭顶之灾，不然不会出手。

**绝巅与帝落**：绝巅是一种介于一步登顶的神奇境界，身上气息几乎与大帝或道尊相同，但本质境界并未到达。三位绝巅合力可达到普通大帝水平。封印自身过久导致生命气息流失的大帝或道尊，境界会随之跌落到绝巅；自斩帝身的大帝和自斩道果的道尊同样会跌落到绝巅，但比普通绝巅厉害得多，可俗称"帝落"境界。这一过程不可逆，若想重新重回至高境界，需要同样的大帝或道尊晋升条件。帝落可以无限接近普通大帝水平。

**大帝与道尊**：这片宇宙的最强者。大帝之间亦分高下，从低到高依次为普通大帝、无双大帝、无上帝。道尊的通常战力下限接近无双大帝，但现有已知道尊中无人达到真正无上帝层次；这描述的是历史已知战力，而不是禁止未来出现更强道尊的天道铁律。

大帝与道尊是两条不同的晋升道路，境界序列（归一→半道→绝巅→大帝/道尊）只表示境界高低，**半道、绝巅并不是成为大帝的必经境界**：

- **大帝路线**：核心条件是获得一缕天道本源。正常帝路为——至少问仙、年龄不超过10万岁、半道以下，参与帝路争锋，获得天道本源，证道大帝。具体历史人物若存在特殊获取方式（如夜帝趁太初古矿暴动窃取本源），以人物条目为准。
- **道尊路线**：不需要天道本源，属于另一条依靠自身大道、极端感悟、大毅力、大机缘，或与当世大帝生死大战而不死的突破道路。半道、绝巅更接近这条道路的发展方向，但并非机械必经公式，以现有历史人物为准。

**帝兵**：与大帝帝位绑定的唯一最高位格本命兵器，与道兵并列为人界兵器法宝的最高层级。

- **本命帝兵形成规则**：每一位大帝必然拥有且只拥有一件本命帝兵。它通常在证道前后由与其大道、生命或长期经历最契合的兵器完成位格升华；不同人物的具体形成时间以人物条目为准。无论何时完成，本命归属一生只有一件。
- **本命归属与持有区分**：本命帝兵永远属于其大帝主人；帝兵可以传承、被后人继承、被夺取、被借用、被其他强者持有、被其他大帝使用。本命归属不随持有者改变（例如【太初鼎】永远属于太初大帝，长生尊等后来者持有或使用它，不改变其本命归属）。
- **使用规则**：帝兵的使用分普通使用与正式激活两个档位。
  - **普通使用**：理论上任何人都可以唤起帝兵最表层的力量，但“能够使用”不等于“所有境界都能稳定发挥接近归一”。低境修士通常只能得到极短时间的护体、威压或一击之力，随后就会因法力、肉身与神魂无法承载而被迫中止；只有自身境界足够高，才能把帝兵的普通状态持续维持在接近归一的表现。普通使用仍不能真正击败状态正常的归一强者。
  - **正式激活**：真正“激活”帝兵威能至少需要无瑕境界——无瑕境界正式激活大约发挥帝兵一成左右威能，可以达到媲美半道的战力；半道强者可以进一步“完美激活”帝兵，大约发挥三成左右威能，远超普通半道，可以与绝巅级存在交锋。
  - 普通使用 ≠ 正式激活 ≠ 完美激活。

**道兵**：与道尊大道绑定的唯一最高位格本命兵器，与帝兵处于同一层级，不设置天然高下。每一位道尊必然拥有且只拥有一件本命道兵，通常在成道前后完成位格升华；具体形成时间以人物条目为准。历史上出现多少位道尊，就代表曾经诞生过多少件本命道兵。其实际强弱取决于原主人实力、兵器特性、使用者、契合度与当时状态。

- **使用规则**：道兵完整沿用帝兵的使用机制——符合条件者可普通使用（接近归一级别战力）；至少无瑕可正式激活（半道级表现）；半道可完美激活（发挥更高比例威能，与绝巅抗衡）。但道兵存在一个帝兵没有的额外门槛：**只有与原道尊血脉相通者才能真正使用该道兵**，非血脉相通者即使得到道兵，也不能调用其力量。
- **存世数量**：当前公开资料能够确认仍留在人界的道兵仅有三件——【悟道剑】【幽冥镜】【天机双生佩】。其他去向未详的道兵不计入公开确认名单，但不能据此断言它们已经毁灭、失落或离开人界。

**飞升后的兵器处理**：大帝或道尊飞升仙界时，可以自行决定把自己的本命兵器带走，或者留在人界。正文明确写留下的，留在人界；明确写飞升且没有写兵器被留下的，默认本命帝兵/道兵随主人飞升仙界；没有说明人物飞升或兵器去向的，写作“去向未详”，不自行创造历史。

**“去向未详”与帝位终止**：史书不知道一位大帝最终去了哪里，不等于天道也不知道。只要后世又正常开启了新的帝路，就说明上一位受天道承认的大帝在天道层面已经结束帝位状态——可能飞升、陨落、自斩或以其他方式脱离人界帝位。否则天道不会再次释放本源。人物条目写“失踪/去向未详”时，只表示后世没有掌握具体结局，不表示其仍以完整大帝境界藏在人界。

**帝路争锋**：当世若仍有大帝存活，便不会有人成就大帝，因为天道不会释放本源；唯有宇宙当中不存在大帝，过数百万年后天道才会释放一缕天道本源，随即展开上万年的帝路争锋，最终大帝诞生，依次轮回。参与者年龄必须不超过10万岁，境界最低为问仙级别（含以上）、半道以下。（双帝时代为天道主动允许的罕见例外，见"大帝更替规则"。）

**斗天九法**：斗天大帝所创的《斗天九法》，九法各代表一个领域的极致，几乎包罗古今以来大帝之法、涵盖万法。九法合一可证得无上帝；后世大帝几乎都会身具几法，但只有斗天大帝做到九法合一。九法后来被斗天大帝分别布入九大禁区，每处禁区对应九法中的一部分传承或考验（具体对应关系未详）。

- **斗仙**（破限之秘）——激发自身潜力至极限，短暂打破境界枷锁、跨阶而战；被逼至绝境时威能尤盛，是九法中"以下伐上"的代表。
- **斗神**（攻伐之秘）——演化诸法、以战养战，可将所见功法神通拆解重构为己用，是九法中的第一攻伐之术。
- **斗鹏**（极速之秘）——取大鹏振翅之意，身法快至极致，可短暂触及时间领域、于对手反应之前完成攻防。
- **斗破**（爆发之秘）——瞬间引爆自身战力，数倍叠加爆发；斗破状态消耗极大，不可久持。
- **斗图**（阵道之秘）——以天地为图、布下绝世杀阵，可将阵法与自身大道相合，一人成阵。
- **斗龙**（驭物之秘）——以龙威驭使万物，夺兵、御器、镇压外物，控兵之术冠绝古今。
- **斗身**（不灭之秘）——锤炼肉身至近乎不灭，受创后极速修复，只剩一口气亦可再生。
- **斗转**（推演之秘）——推演万法变化、洞察对手破绽与战局走向，料敌机先。
- **斗灵**（元神之秘）——修炼元神神识，感知入微，可预知凶险、察觉天机变动。

### 种族

这世间共有九大种族：人族、妖族、龙族、天族、灵族、神族、魔族、鬼族、冥族。九族是对主体文明与生命谱系的最高层级划分，不代表宇宙中只有九种血脉；大量古兽、异种、混血、灵体与地方族群会被归入最接近的九族体系。

**人族**：分布最广、总体人口最多的种族之一。单论先天血脉，人族通常不及神族、龙族等强族，但个体差异极大，繁衍速度快，对功法、法宝和制度的兼容性极强。人族最擅长以宗门、王朝、家族、书院和商盟组织大规模社会，因此许多跨域制度、通用功法与大型城池都带有明显的人族影响。人族内部并不天然团结，不同王朝、宗门和世家之间的冲突往往比跨族矛盾更加频繁。

**妖族**：不是单一血脉，而是规模最大的非人形生命共同分类之一。草木、飞禽、走兽、异兽乃至部分天地精怪在诞生稳定灵智、形成独立修炼传承后，都可能被归入妖族。妖族内部血脉差异极大，从普通兽类启灵到洪荒遗种均有，强者高度依赖血脉、悟性与后天蜕变。化形只是常见选择而非强制要求。由于支脉繁多，妖族整体实力极强但天然分散，历史上古藏大帝、武帝等人都曾尝试建立跨支脉共同秩序。

**龙族**：历史最悠久的独立种族之一，不归入妖族。每个时代都最少有一名半道守护龙。最强的几个支脉堪称全宇宙最强之一，底蕴极深，往往能够同时掌握三四件帝兵，甚至更多，是人界最具历史积累的族群之一。祖龙大帝统合宇宙龙族，划分青龙、应龙、烛龙、苍龙、玄冥龙五大主支脉；蛟族、亚龙与混血龙裔是否属于龙族核心成员，则由各支脉血统规则决定。

**天族**：与神族并非同族。天族天生更容易感知天地法则与天象变化，部分血脉出生时会形成“天纹”，使其在阵法、天机、空间、雷霆等方向拥有优势。天族社会重视血统谱系、契约和秩序，但不像神族那样高度封闭；古仙大帝之后，天族逐渐建立了独立于神族的修炼体系与政治传统。其弱点是过度依赖天地环境时，容易受到绝灵区域、法则紊乱区和特殊禁区压制。

**灵族**：古老而神秘，诞生于宇宙初开的灵能漩涡。严格意义上的纯血灵族长期只有数百人，九星秘境域中数量更多的灵裔、附属家族和灵能生命并不全部计入“纯血灵族”人口。灵族天生能与灵能沟通、操纵灵能化为强大力量，法术独特多变。普通纯血灵族自然寿命约千年；灵族存在特殊种族寿命例外——普通半道寿命约100万年，而灵族半道因生命结构特殊可达到约1000万年。灵族内部以家族与九大灵脉为核心，结构松散，虽有内部竞争，但遇外族威胁往往会迅速联合。古灵大帝飞升前分化灵体为九大灵脉，成为灵族延续至今的根基；化灵大帝则曾自碎本源灵核修复九星秘境域灵能漩涡。

**神族**：自人界早期便存在的稀少强族，拥有极高的平均先天天赋。神族所居核心区域被统称为神域，通常由浮空神城、神山与封闭小世界构成。神族族人诞生时常伴随神力异象，对神力与高阶术法的感知远强于多数种族，但“平均天赋最强”不等于同境必胜；人数稀少、血脉繁衍困难、社会封闭也是其长期弱点。神族尤其重视血统纯度、神术传承与个体培养，因此往往以少量顶尖强者维持巨大影响力。

**魔族**：以魔躯、魔血与极端环境适应力著称，主要聚居地之一是天朝域魔骨血海周边。魔族修炼往往强调肉身蜕变、吞炼、血契与雷劫淬体，但“魔”是生命与修炼体系分类，并不等同于天然邪恶；魔族内部同样存在王朝、宗门、部族与守序势力。由于部分古魔功法会吞噬血肉、魂魄或环境资源，魔族与其他种族的历史冲突格外显眼。

**鬼族**：由阴灵、魂体、时空残灵以及部分死亡后稳定转化的生命构成，既有自然诞生者，也有后天转化者。鬼族通常没有与人族完全相同的肉身结构，更擅长神魂、阴气、诅咒与时空类能力。鬼族不等于亡魂集合体：普通死者不会自动成为鬼族，必须满足特定环境、功法或本源条件才能形成稳定自我。九幽仙宫与葬神墓地都是鬼族历史上最重要的危险区域。

**冥族**：太古时期由神冥道尊建立的独立生命谱系，与鬼族有本质区别。冥族拥有稳定的冥躯与可延续血脉，本源偏向黑暗、生死与冥河力量，不需要以亡魂状态存在。冥族长期在宇宙暗处发展，擅长隐藏、替死、魂魄与生死类术法。古月大帝陨落后，【葬月轮】与月光本源传入冥族；神冥道尊的【幽冥镜】封存月光本源，每逢特定月相会引发“阴阳暴动”，成为冥族重要修炼机缘。

**十大神兽**：凤凰（神凰大帝）、麒麟、梼杌、獬豸、犼、重明鸟、毕方、饕餮、白泽（白朴大帝）、祖龙（祖龙大帝）。洪荒时代万族林立、野兽争霸，演化万年诞生了十大神兽，各占其地、不分高下，以这十族为最强种族，其他种族夹缝求生，其中人族成为各大种族最喜爱的食物、濒临灭绝。直到太初大帝现世横扫十大神兽，终结了这一时代。

### 势力

**归一联盟**：人界延续时间最长、影响范围最广的顶层势力联盟，也是当今宇宙公认最具影响力的政治组织。

但严格来说，归一联盟并不是一个独立统治八域的中央政权，也不是一个拥有完整疆域、军队和基层行政体系的单一势力。它更接近一个由宇宙中大量顶级势力、归一境强者以及少数独立强者共同组成的长期合作体系。

全宇宙约有二百三十位归一境强者，其中约一百六十位拥有归一联盟成员身份。这并不意味着联盟直接拥有一百六十位归一强者——绝大多数联盟成员首先属于自己的宗门、家族、种族、神朝或其他势力，其次才是归一联盟的一员。例如，一名李族归一强者首先是李族老祖，同时也可能兼任归一联盟长老；龙族强者首先代表龙族利益，在联盟中才拥有自己的席位和影响力。因此，归一联盟所谓的“实力”，更多代表它在极端情况下能够调动、联合和影响的力量，而不是一支随时听从统一命令的直属力量。

**联盟的形成**：归一境已经属于能够真正影响一域乃至宇宙格局的顶级力量。当越来越多归一强者与顶级势力出现之后，各势力逐渐发现，一些事件已经无法依靠单一宗门、单一种族或单一区域解决——大规模种族战争、禁区暴动、帝兵复苏、半道强者冲突、跨域灾难，以及可能导致整个宇宙秩序失控的事件，都需要多个顶级势力共同处理。归一联盟最初因此诞生。它并不是为了消灭势力竞争，而是为了在所有顶级势力之上建立一个能够沟通、谈判和协调共同利益的平台。随着越来越多强者加入，联盟最终成为宇宙顶层强者默认参与的政治体系。发展至今，绝大多数公开活动、拥有正常势力背景的归一境强者都会与联盟保持某种程度的联系。这也是归一联盟被称为“宇宙第一势力”的真正原因。

**联盟不统治地方**：归一联盟原则上不管理普通星球、宗门、国家和地方势力之间的日常事务。帝星上的宗门可以争夺资源，神朝之间可以发动战争，两个顶级家族可以互相吞并附属势力，宗门之间可以争夺秘境、灵脉、星域和传承，甚至联盟成员所属的势力之间也完全可以爆发激烈冲突。这种竞争本身就是人界正常秩序的一部分。归一联盟既没有能力，也没有意愿消灭这种竞争。联盟真正关注的不是“有没有战争”，而是这场战争是否已经扩大到足以破坏整个宇宙顶层秩序的程度。

**联盟的组织结构**：联盟内部大致分为四个层级。

- **外门执法**：主要负责联盟日常事务、调查、传讯、维护联盟据点以及执行已经通过的普通决议。成员通常是极有希望踏入归一境的强者，其中也有少数归一境成员。外门执法是联盟中最接近“直属成员”的群体之一。
- **内门执法**：主要负责跨势力调查、处理高阶冲突以及执行长老院已经形成的决定。成员至少达到归一境，通常拥有较高资历。相比普通联盟成员，内门执法对联盟本身拥有更强的身份认同。
- **长老院**：归一联盟真正的最高议事机构。长老通常至少达到合一层次，总数长期维持在五十人左右。五会通常占据约三十席；龙族、灵族、冥族、神族等其他大型势力与种族约占十席；另外约十席长期由没有明确大型势力背景的强者、散修或者中立人物占据。长老院最重要的作用不是直接统治联盟，而是代表不同利益集团讨论并决定联盟是否采取集体行动。
- **联盟领袖**：每隔一万年推举一次。领袖拥有最高主持权，可以召集长老院、提出议案、协调各方、调度联盟直属资源，并在已经通过的决议范围内主持行动。但领袖并不是宇宙意义上的皇帝——涉及顶级势力、归一强者、种族战争以及大规模军事行动的重大问题，领袖不能凭个人意志决定。真正能够代表归一联盟整体的重大行动，必须经过联盟内部表决。

**表决制度**：归一联盟最重要的制度，也是它最大的限制，就是**重大决策必须经过投票**。联盟不是一个上下级分明的组织；联盟长老背后往往就是某个宇宙顶级势力，因此每一次重大表决，本质上都是不同势力之间的一次政治博弈。普通事务可以由领袖、执法机构或者部分长老直接处理，但涉及以下事件时一般必须提交长老院：对一个顶级势力进行正式制裁；对归一境强者采取强制措施；联盟以整体名义参加战争；干涉大型种族冲突；调动大量联盟资源；集体动用帝兵；处理半道、绝巅级事件；决定足以改变一域乃至宇宙格局的重大行动。只有获得足够多数支持，议案才会成为归一联盟的正式决议；没有通过表决，就不存在所谓“联盟意志”。

**联盟最大的矛盾**：归一联盟最强大的地方，也是它最脆弱的地方。因为宇宙中最强大的势力几乎都在联盟内部。当威胁来自联盟之外时，联盟往往非常容易形成共同立场——例如某个未知势力突然袭击多个种族、禁区发生可能席卷八域的暴动，或者某个脱离现有秩序的绝巅强者开始无差别屠杀。这类事件几乎损害所有成员的共同利益，一旦长老院迅速通过决议，联盟就能够在短时间内联合大量归一强者、帝兵以及顶级势力，此时几乎没有任何单一势力能够抗衡。但如果问题发生在联盟内部，情况完全不同：假设李族与另一顶级家族爆发全面战争，李族必然会利用自己在联盟中的影响力推动制裁，另一个家族同样会发动自己的长老、盟友和利益相关势力反对该议案。与双方有利益关系的势力会迅速站队，五会内部可能分裂，其他种族可能保持中立，散修长老可能拒绝参与。最终即使外界战争已经非常激烈，联盟内部仍然可能无法获得足够票数，联盟便无法以整体名义介入。

**联盟成员之间的战争**：联盟成员身份并不意味着彼此不能成为敌人。两个联盟成员可以在外界交战，两个联盟长老所属的势力也可以爆发战争——甚至可能出现双方在自己的疆域中已经杀得极其惨烈，而几日之后两方代表仍然同时出现在归一联盟长老院中参加另一项宇宙事务的表决。联盟只代表一种更高层次的合作关系，并不会抹除成员原本的利益冲突。如果联盟无法形成统一决议，那么其他成员势力仍然可以自行选择立场：有人可以帮助李族，有人可以帮助它的敌人，有人可以保持中立，有人可以出面调停——但这些都只是各势力自己的行为，只有长老院正式通过决议之后，才能称为“归一联盟介入”。

**决议与执行**：即使联盟通过决议，也并不代表一百六十位归一强者会同时听令行动。联盟真正能够直接控制的力量有限：执法机构、联盟据点、公共资源以及部分长期效忠联盟的强者属于联盟最稳定的直属力量；更多情况下，重大行动仍然需要各成员势力共同出人、出资源、出帝兵。因此联盟的战争能力可以分成两个概念——**潜在实力**与**实际动员实力**。从潜在实力来看，没有任何势力能够与归一联盟相比；但真正能够投入某一次行动的力量，取决于有多少成员支持这项决议，又有多少成员愿意真正付出自己的力量。一项决议即使通过，如果支持度并不高，最后实际参加行动的势力也可能十分有限；相反，当整个宇宙真正面对共同灾难时，绝大多数成员同时响应，归一联盟才能展现它作为宇宙第一势力真正恐怖的一面。

**联盟与帝兵**：归一联盟长期掌握十余件帝兵，其中多数归五会或联盟核心成员控制。帝兵“由联盟掌握”不等于联盟拥有本命归属，只表示保管、控制或实际调用权。

**五会**：联盟内部影响力最大的政治集团被统称为“五会”——李族、神武族、古夜族、帝兽族、星族。五会并不是联盟的主人。它们之所以长期掌握最大话语权，是因为五大势力本身就拥有极其庞大的底蕴、归一强者、帝兵、附属势力以及复杂的盟友网络；五会通常能够控制长老院的大量席位，因此任何重大决议都很难完全绕开它们。但五会本身并不是一个永远保持一致的集团，它们彼此之间同样存在竞争、利益冲突甚至敌对关系。所谓“五会主导联盟”，真正含义是“联盟中最有能力影响表决结果的五个大型政治集团”，而不是五个共同统治宇宙的家族。

**联盟真正维护的东西**：归一联盟从来没有真正消灭过战争，它也不会为了维护所谓“和平”阻止所有强者和势力竞争。联盟真正维护的是一种所有顶级势力都能够接受的最低限度秩序：宗门可以战争，种族可以竞争，归一强者之间可以存在仇恨，势力可以兴盛也可以衰亡——但各方通常不会轻易允许某一次局部冲突无限扩大，最终把整个八域拖入无法控制的毁灭性战争。归一联盟存在的意义，就是在这种情况真正出现时，为整个宇宙提供一个仍然能够进行谈判和组织联合行动的平台。因此，归一联盟真正的特点并不是“拥有绝对统治力”，而是：当宇宙顶级势力拥有共同利益时，没有任何组织比它更强；当这些顶级势力彼此冲突时，也没有任何组织比它更容易陷入政治僵局。**归一联盟的强大来自共识，归一联盟的限制，同样来自共识。**

**大势力标准**：有一位归一强者坐镇即可被称为大势力；至少三位归一强者长期坐镇，通常可被视为顶尖势力。帝兵、半道老祖、历史盟约等特殊底蕴可以使实际威慑力高于纸面评级。

### 普通社会与日常规则

人界的高端叙事以归一、大帝和禁区为核心，但绝大多数生灵一生都生活在凡俗世界与低阶修士社会中。为了保证世界在“没有大帝出场”的地方仍然能够运转，采用以下通用规则：

- **社会组织**：凡人王朝、城邦、宗门、家族、部族、商会和书院并存。一个生命世界可以由单一王朝统治，也可能由多个宗门或国家分治；没有宇宙统一模板。
- **修炼教育**：低阶功法并不绝密，练气与筑基阶段的基础法门在多数成熟世界都能通过宗门、家族、军队、书院或市场获得。真正拉开差距的是高阶功法、资源、师承、体质和进入秘境的资格。
- **通用货币**：普通社会使用各地金银、钱币或信用凭证；修士之间最常见的硬通货是灵石。灵石按纯度与灵气含量分级，不同地区叫法可以不同，但大型商会会统一折算。归一以上交易往往不再单纯以灵石计价，而以稀有材料、法则结晶、帝级遗物线索、禁区名额等交换。
- **交通**：同一星球或小世界内主要依靠飞舟、坐骑、传送阵；跨星系依赖大型星舟与星门；跨域通行昂贵且受大势力控制。归一强者可以长期横渡虚空，但仍不等于瞬间抵达八域任意地点。
- **通讯**：短距离使用传讯符、玉简、神念法器；跨星域依赖大型传讯阵与商盟节点。越远、越危险的区域延迟越明显，禁区与法则紊乱区甚至会完全隔绝消息，因此“消息不对称”在高阶世界依然普遍存在。
- **法律与秩序**：地方规则由当地政权或宗门制定；归一联盟只在跨域与高阶事件上拥有普遍公认的仲裁权。强者可以破坏规则，但破坏规则会引来更强势力、资源封锁、通缉和盟约反制，而不是毫无成本。
- **人口与修士比例**：凡人和练气以下生灵占绝对多数；境界越高人数越少。归一强者全宇宙约230位，因此普通修士可能一生都没有亲眼见过归一，更不用说大帝或道尊。

### 历史

**时代划分**：超时代、鸿蒙时代、乱神时代、三清时代、洪荒时代、神化时代、拓荒时代、太古时代、天武时代、开盛时代。三清往上的历史属于仙界篇。

**洪荒时代**：人界被开辟后宇宙空荡、法则尽失，道德天尊兵解化身使生机复苏。第一个时代为洪荒时代，万族林立、野兽争霸，演化万年诞生十大神兽，各占其地、不分高下；人族成为各大种族最喜爱的食物，濒临灭绝。一眼万年，天地灵气趋于饱和，人族妖族包括其他种族渐渐崛起，逐渐能与十大神兽的种族分庭抗礼。

**神化时代**：标志是人族诞生了第一位真正的大帝——太初大帝，横扫天地、无人能敌，万族共尊。太初大帝以融合十大兽族血肉的帝兵【太初鼎】镇压人族气运，横扫十大神兽（有的兽族只剩下零星血脉），终结了十大神兽的辉煌；游历宇宙万年、踏遍宇宙每一寸，只身踏入禁区、杀得禁区不再有禁忌存在。临终前他感到天地法则排斥、意识到即将飞升仙界，便把禁区收获结合到一起开辟了太初古矿，将珍宝（包括帝兵【太初鼎】和《太初法》）放进深处，后不知去踪。

**历代帝级存在年代记**：下表属于公开正史谱系，共61位帝级存在——53位大帝、8位道尊。**长生尊因证帝后斩断天道联系、从未进入公开帝谱，不计入这61位；若计入隐秘历史，当前已知至少存在54位大帝、8位道尊，共62位帝级存在。**括号内为种族。

**神化时代**

- **太初大帝（人）**——神化时代的开端，也是人界第一位真正的大帝。洪荒末世，他以【太初鼎】横扫十大神兽，为濒临灭绝的人族夺下一席之地；此后独行八域、踏遍禁区，几乎以一人之力重新划定了万族对“至强者”的认知。飞升前，他将一生所得封入太初古矿，留下【太初鼎】与《太初法》，自此不知所踪。后世尊其为古今第一位无上帝。
- **混沌大帝（神）**——神族出身，一路帝路无败，最终以混沌体证道。其《混沌战决》霸烈无双，却因门槛极高而另建混沌圣堂择徒；后来从太初古矿得《太初法》，转而穷究修炼根基，创出适用于万族的《天元法》，对后世修炼体系影响极深。本命帝兵【混沌战甲】，晚年飞升仙界。
- **道衍大帝（妖）**——本体是一株仙草，较少以征伐留名，却以传道影响后世。成帝后创《锻灵法》《启灵法》，又编成《帝经》三篇，门下九位最强弟子被称为“九天战神”；所谓“合一能屠帝”只是后世盛誉，并非真实境界换算。晚年开辟道衍界，将殿堂与《帝经》最终篇藏入混沌，自此失踪。本命帝兵【道衍叶】亦去向未详。
- **逆天大帝（人）**——生于乱世，一生几乎都在与既定秩序相争。年轻时数十次与长生尊交锋，最终于生死之间悟出《逆天决》并将其击败；成帝后又发现天尊残留恶念侵蚀天道，遂与之决战。那一战几乎斩灭恶念，也使他肉身消散、神魂破灭。其本命帝兵【逆律剑】随之失落，去向至今未明。

**拓荒时代**

- **天帝（神）**——神族出身，却主动破去神体，以千年重炼混沌体，并从混沌圣堂习得《混沌战决》。他与已经走到帝路前列的人帝从生死宿敌打到彼此认可；人帝先以正常天道本源证道后，天道在极罕见的特殊节点又主动释放第二缕本源，天帝于混沌中完成证道，由此形成已知最著名的双帝时代。两帝随后共创《天人经》。共治十万年后，两人为追索长生与天道桎梏，接受《长生经》并主动自斩帝身，隐入禁区，与长生尊并称三大神尊。本命帝兵【天帝剑】。
- **人帝（人）**——比天帝更早证道，也是双帝时代的另一根支柱。其本命帝兵【天穹刀】由【太初鼎】祭炼而成，古意极重；与天帝由死战走向共治后，两人共同完成《天人经》，维系宇宙十万年安稳。此后同样为追寻更高道路而自斩帝身，潜入禁区，成为三大神尊之一。
- **古帝（妖）**——拓荒时代第一位妖族大帝，本体为九日神鸟，并兼有梼杌血脉。其战力并非同代最显赫，悟性却少有人及，一生留下《神文经》《平乱决》《铸体经》《古仙法》《九势决》等诸多传承。帝兵【证仙】本身便是一部经文。晚年将传承与帝兵留在人界后飞升仙界。
- **神凰大帝（妖）**——洪荒凤凰之祖，曾被太初大帝真正斩杀；凤凰不死本源在死亡后完成了一次完整涅槃，以新的凤凰生命重新孕育于混沌，而不是把旧肉身简单封印。因此她再度出世时拥有新的生命年轮，仍符合帝路年龄限制，但洪荒时期的修为已经失去，只保留部分本源与记忆。她凭借近乎无与伦比的天赋迅速重修，几乎没有经历真正意义上的帝路苦战便横压群雄，创《不灭经》、炼十颗不灭丹，并开辟无尽深渊。她曾一人逼退三大神尊，后来又封印天神尊、重创人神尊，最终与三大神尊订下自封百万年的约定。留下不灭界与【不灭神羽】的传说后飞升仙界，被视为最接近无上帝的无双大帝。
- **灭帝（人）**——幼年服下不灭丹，炼成不灭体，却也很早经历灭族之祸。此后他在追杀中一路成长，问仙时便执【灭仙剑】血洗仇敌，甚至越境斩杀归一老祖，“灭”之名由此传遍宇宙。成帝后创《三转法》《灭仙决》，留下传承后飞升仙界。
- **斗天大帝（妖）**——月狼族出身，少年时遍参帝法、闯禁区、数度涅槃，最终将所学熔为《斗天九法》，九法合一后证得无上帝。其一生最重要的发现并非征服禁区，而是在与“化道”强者交锋中确认了大帝之外另一条通天大道，并将不圆满的阶段命名为“半道”，再把所得传给独子唯尽。后来他开辟堕仙界，将九法散入九大禁区。本命帝兵【九法战戟】，但他本人始终更信自己的法，极少借兵取胜。最终飞升仙界。
- **剑帝（人）**——青年时长期平定动乱，被人族视作守护者；成帝后创建飞仙教，以【飞仙剑】和《飞仙决》维系人族与宇宙秩序，门下二十四剑星中更有三人踏入半道。后来他与唯尽道尊相争数千年，在一次次败战中不断磨剑，最终借《不灭经》与不灭丹迈入大帝巅峰，与唯尽几近持平，随后飞升仙界。
- **唯尽道尊（妖）**——斗天大帝独子，自幼承父法，又曾随剑帝修行。踏入半道巅峰后，他主动逼剑帝全力一战，以断臂为代价在生死间悟道，成为道尊；此后与剑帝连战数千年，留下“十战九胜一平”的传说。剑帝飞升后，唯尽独自坐镇人界约百万年；这一时期恰处于上一帝位结束后的漫长空窗，天道尚未再次释放本源，后世因此常把这段岁月称为“唯尽镇世”。道尊本身并不会阻止帝路开启。晚年留下《唯尽法》与本命道兵【悟道剑】，随后飞升仙界。
- **九玄大帝（妖）**——本体为犼，以【九玄扇】为证道路上的关键依仗。成帝后创九玄殿、传《九玄法》，广收门徒，使其一脉长期活跃于妖族。其本人后来去向未详，而【九玄扇】最终传入万妖阁，成为妖族最重要的镇族兵器之一。
- **铸天大帝（天）**——天族出身，天生亲近天地之力，年轻时长期游历八域、与诸族强者交锋，始终以天族崛起为志。成帝后创《补天经》，其本命帝兵【补天剑】也逐渐成为天族象征。晚年没有留下明确飞升记录，只知最终消失于宇宙深处。
- **古元大帝（人）**——出身普通人族部落，没有显赫血脉，也没有惊世开局。资源匮乏与长期战乱反而塑成了他极强的韧性；游历诸域后，他融汇百家所学，创出《古元经》，并以【洪荒塔】镇守人族一方。其一生常被后世视作“凡身亦可登帝”的象征，最终飞升仙界。

**太古时代**

- **祖龙大帝（龙）**——第一世生于洪荒末年，先天混沌龙体，因血脉过烈遭族群驱逐。太初大帝崛起后，他曾以分身挑战太初，三招即灭，本体亦遭重创；此后仿凤凰真正涅槃的原理自创《归墟涅槃法》，主动毁去旧龙躯与绝大部分修为，把本源化作无意识龙卵。龙卵在混沌中孕育数千万年后诞生第二世祖龙，生命年轮自破壳重新计算，因此能够合法进入帝路；他再世重炼祖龙体，最终踏过帝路证道。成帝后历经九万年征战统一龙族，划定青龙、应龙、烛龙、苍龙、玄冥龙五大支脉，留下【祖龙玺】与诸法后飞升仙界。
- **古月大帝（妖）**——其生命源头可追溯至洪荒末年：吞月天狼与月桂神树共生时留下一枚没有完整意识的“残月胎”，此后长期漂流并沉寂于星空，直到太古时代前夕才真正孕育出独立生命古月。因此“生于洪荒末年”是后世对其本源年代的简称，并不意味着古月本人以完整生命活了数千万年。古月少年时期曾遭獬豸残脉追杀，寄身残月漂流三千年，炼成月蚀妖体；之后借太初鼎碎片与太阳精魄补全阴阳道基，最终证帝。其《古月经》以月蚀、葬月、太阴三卷闻名，本命帝兵为【葬月轮】。晚年与神冥道尊爆发持续八百年的“日月之战”，最终陨落，月光本源与帝兵却由此传入冥族。
- **神冥道尊（冥）**——葬神墓地孕育的先天冥灵，也是后来冥族的奠基者。与古月大帝相争八百年间，他以《往生咒》、替死傀儡等冥术一次次从死境中脱身，并在生死磨砺中晋升道尊。最终借太初古矿的时间裂隙避过“月殒”，反杀古月。本命道兵【幽冥镜】封存月光本源，自此成为冥族圣物。
- **古灵大帝（灵）**——诞生于灵能漩涡，天生掌握七十二道灵纹。成帝后曾独力镇压魔骨血海暴动，并以其中十万凶灵铸成【灵枢】；与应龙三百年死战中，他有意留下生机，使对方最终踏上道尊之路。此后创《古灵经》，飞升前又分化自身灵体为九大灵脉，为灵族留下延续至今的根基。
- **应龙道尊（龙）**——出自应龙支脉，早年为祖龙大帝关门弟子，承其三大传承后一路修至绝巅。为求突破，他剜下逆鳞挑战古灵大帝，龙身被【灵枢】击碎后借青龙精血与天罚涅槃，最终炼成万劫龙体、晋升道尊。此后创《应龙法》，并铸本命道兵【劫道刃】。晚年去向不明，道兵亦随之失踪。
- **释天大帝（人）**——曾九次自废修为、九次重修，最终炼成九转金身，并以《释天经》奠定后世佛修根基。他曾独闯魔骨血海，以【释天剑】钉杀半道魔祖，也曾点化后来证帝的古佛。飞升前，释天斩出自身恶尸“灭世尊”，却又以善念将其镇压于古佛宗，从此留下佛门关于善恶二性的最早传说。
- **古仙大帝（天）**——天族九窍仙心，少年时便以强横天资震动族内。其真正影响在成帝之后：重订天族修炼体系，创《古仙法典》，使天族逐渐摆脱对神族的依附；又斩神族伪帝、夺其神格铸【戮神矛】。后来更以三成修为化作葬仙链，永久锁住无道死地核心，为天族留下最重要的底蕴之一。
- **化灵大帝（灵）**——灵族大帝，一生最重“化”与“融”。九星秘境域灵能漩涡崩溃时，他自碎本源灵核重塑天地，残片凝成【万灵鼎】；随后又创《化灵经》，尝试打破不同种族功法间的壁垒。其后将兽谷炼作“万妖灵冢”，作为灵族试炼地，最终飞升仙界。
- **古魔大帝（魔）**——诞于魔骨血海，以吞噬古魔残骸成就不灭魔躯，修行之路始终伴随雷劫与杀伐。其《古魔经》反用天劫淬炼自身，本命帝兵【万魔塔】更曾囚禁十二位各族强者以供养魔土。成帝后，他与神冥道尊暗订血契，为魔族与冥族建立长期同盟。晚年不知所踪。
- **祖鹏大帝（妖）**——起于北海之极，吞上古鲲兽而兼得海、空两极道则，最终炼成帝兵【天鹏骨翼】。其一生以极速著称，《九霄鹏程诀》几乎将空间本身化作道路；成帝后平定九部古妖族叛乱，并将精锐炼为鹏影卫。后来又在葬神墓地留下鹏族图腾，为后世妖族进出禁区留下一线生机。
- **夜帝（人）**——没有沿正常帝路登临，而是在太初古矿暴动时以《暗蚀经》遮蔽天机，趁机夺取天道本源成帝。其后斩九光神子、以神骨铸【夜狩】，并与李族、古夜族等人族势力结盟，留下多支暗系秘法。晚年与无天道尊大战至平，双方立契止战；夜帝随后飞升仙界。
- **无天道尊（神）**——神族弃子，以反抗血脉与天道烙印走出自己的道路。趁夜帝征战时，他引神罚天劫硬接【夜狩】三箭，又夺舍九光神子残躯、剥去神族血脉中的天道印记，终于在大战中晋升道尊。战平夜帝后，两人以《暗蚀经》与神族默许夜影阁存在为条件订下契约。其后飞升仙界，本命道兵【逆命梭】随行。
- **古藏大帝（妖）**——妖族中少见的文明奠基者。早年吞炼九大禁区凶兽精魄，并以此铸成本命帝兵【炼神妖壶】；成帝后却把更多精力放在整合妖族，创《古藏妖典》、统一妖族文字，使散落八域的妖族第一次拥有共同的文明文本。其门人后来成为万妖宗核心，奠定妖族在帝落域的长期优势。古藏本人最终失踪。
- **神龙大帝（龙）**——玄冥龙支脉异种，逆炼青龙精血后又显应龙金翼、烛龙瞳纹，成为少见的三脉合一龙皇。其本命帝兵【玄冥镇界戟】以蛟珠铸成，寒力极盛。祖龙飞升后龙族一度动荡，神龙大帝趁势镇压苍龙、烛龙两脉叛乱，并重新划定五大支脉疆域，今日古域龙族格局多由此定型。
- **道天大帝（人）**——生具道源灵体，最擅观察与推演天道运行。成帝后创《道天经》，又以天道碎片铸【天衍盘】，其治世同样偏重秩序与布局：镇压妖族动乱、重划帝落域势力，后来五会格局中人族三会的早期根基便在这一时期形成。飞升前，他将部分天道感悟封入天机阁，【天衍盘】则随其一同离开人界。
- **天姬道尊（妖）**——本体九尾天狐，靠吞炼古妖血脉走到绝巅。她曾以“九尾迷天阵”扰乱天机，与前来查探的道天大帝争锋；战至最后，两人从斗法转为论道，三日之后天姬借此踏入道尊。此后两人共铸【天机双生佩】并立天机碑，奠定人妖两族长期共掌大势的格局。天姬最终飞升，双生佩却化作双子星留在人界。
- **长河大帝（妖）**——本体为洪荒异种时河鲲，天生亲近时间大道。其本命帝兵【时河钟】可回溯极短时间，却以寿元为代价；《长河经》则把这种对时间的理解整理成妖族可学的体系。飞升后，围绕时河钟仿品与时墟形成的传承仍掌握在极天妖族手中。
- **古佛大帝（人）**——原只是释天大帝点化的一名扫地老僧，亲眼见过“灭世尊”之乱后才真正悟透善恶。其后创《古佛经》慈悲、明王、轮回三卷，又以释天剑碎片与灭世尊残躯炼成【因果轮】。成帝后镇压鬼族、炼七十二鬼王入镇魔塔，奠定佛修在宇宙中的地位。飞升前又斩出善尸“渡世尊”留守古佛宗。
- **时空大帝（鬼）**——诞生于葬神墓地的时空鬼灵，自幼便能触及零散的时间碎片。蛰伏九幽仙宫期间，他吞噬上古鬼皇、彻底觉醒时空天赋，后取青铜古棺核心铸成本命帝兵【时空刃】。成帝后创《时空经》，成为鬼族后世最重要的根本法之一。其晚年没有可靠记载，最终不知所踪。

**天武时代**

- **武帝（妖）**——太古魔猿与混沌石灵共生之躯，因力量过盛而被妖族排斥，却也因此走出“以战养战”的道路。成帝后，他将个人武道整理为《武帝战典》，创建万妖武殿与生死武斗场，又以万兵熔炉铸成【荒武战甲】。门下九大武尊、六支新族群与后来的“武劫制度”，使其影响远超一代帝者本身，天武时代也由此真正成形。
- **天妖大帝（妖）**——其本源相传可追溯至洪荒第一缕妖气；那缕妖气在漫长岁月中散入万妖血脉，直到天武时代才重新聚合出稳定自我，因此并非一个拥有完整意识的个体从洪荒直接活到天武。天妖无形无相，能够拟化万妖。吞炼诸多洪荒凶兽后，他炼成万妖源体，并以【万妖幡】召引古妖之灵，发动“万妖劫”席卷帝落域。飞升时，天妖大帝主动引爆万妖幡，将其中妖灵散入妖族血脉，后世所谓“狂化”天赋便由此而来。
- **天鹏大帝（妖）**——吞天云鹏与雷泽神鹰的混血后裔，因血统不纯被鹏族放逐。独居飞仙域罡风层万载后，他以九天神雷炼成九劫雷鹏体，最终证道大帝。本命帝兵【裂宇爪】曾撕开楚域大片疆土，留下经年不合的“天痕”；其本人也因此成为天武时代最具速度与破界威名的妖帝之一。
- **赤凤道尊（妖）**——血焰凤凰与冥火幽凰的变异血脉，幼年因生灭之火失控而被流放魔骨血海。她在那里吞炼凶灵、炼成生死凤炎，并以褪羽铸本命道兵【焚界铃】。与天鹏大帝的最终一战中，赤凤燃尽凤炎、与其同陷“生死火冢”，在死生一线间完成突破，成就道尊。此战余波甚至改变了九龙谷部分空间结构。
- **天蛟大帝（妖）**——北海蛟族的混血异种，兼具玄冥血蛟与洪荒雷鳗之力。被放逐魔骨血海后，他以古魔残骸炼体，帝路中更强夺天道本源、引九重混沌劫证道。成帝后创《化龙经》，本命帝兵【镇海雷狱戟】以寒雷著称。晚年因吞不灭凤炎闯入无尽深渊，最终遭洪荒妖灵反噬，帝躯崩毁，临死自爆帝兵，其雷暴残威至今仍留在深渊。
- **武凤大帝（妖）**——凤凰与魔猿血脉融合而生，兼具火焰与纯粹肉身之力。成帝后曾统一妖族，创建焚天宗，以《焚天经》培养后辈；本命帝兵【荒焰战甲】也因此成为天武时代最著名的战甲之一。与许多成帝即求飞升者不同，他长期留在人界经营妖族未来，留下了极深的时代烙印。
- **天儒大帝（人）**——人族儒道的真正奠基者。早年遍读诸经、游历诸域，在人族衰弱时期重新整理教化与修行之关系，最终创《天儒经》，以仁、义、礼、智、信构成一套独立修炼脉络。成帝后以【天儒笔】传法立教，使儒道第一次成为足以影响人族格局的大道体系，晚年飞升仙界。
- **丈史大帝（人）**——出身古老人族世家，自幼便对历史长河有异常敏锐的感知。其后创《丈史经》，尝试将历史、时间与因果整理成可修之道；本命帝兵【史册】则成为承载这条道路的核心。成帝后，他多次以自身对历史脉络的理解介入大势转折，被后世视为最难以用单纯战力评价的大帝之一。最终飞升仙界。
- **龙帝（龙）**——龙族后世最具传奇色彩的大帝之一，天资近乎天生无敌，很早便走出独属于自己的“龙道”。成帝后，他不以繁复法则见长，而以龙躯、龙道与天地共鸣镇压诸敌，甚至曾击败三大神尊。本命帝兵【龙皇印】与龙族至宝【龙魂珠】皆曾随其征战，但其根本道路从不依赖外物。晚年飞升仙界，龙族也因其时代积累而再度走向鼎盛。
- **浮龙大帝（龙）**——一生追求不灭之躯，也执着于重建龙族绝对权威。修《浮龙无极诀》成帝后，他以【浮龙紫电矛】驾雷破空，又借星辰灵气修成“浮光”领域。其统治时期主要精力都用于镇压龙族内外叛乱、重整秩序，最终重新稳住龙族霸业。
- **振武道尊（妖）**——承接妖族古老武道而起，修《振天无极诀》，能以天地元气化出万千战影。其本命道兵【武尊铁拳】以纯粹破法见长。比起开宗立派，振武更重要的贡献是重新梳理妖族古武体系、整合彼此割裂的武道传承，并在这一过程中走到道尊层次。晚年与道兵去向均未详。
- **截天大帝（天）**——天族强硬一脉的代表人物，修《天道断裂术》，以“截”字贯穿自身大道。本命帝兵【断天弓】长于破隐、破界与远距离杀伐。成帝后，他以极强手腕压服诸敌、重整天族，使天族势力一度横跨大片星域，重新回到宇宙最强族群之列。
- **斩天大帝（天）**——出身天族，以《斩天破界诀》入道，一生杀伐极重。其本命帝兵【破天剑】锋锐无匹，最擅正面破阵与斩界。成帝后长期征战诸族，以近乎不退的战斗风格坐稳天族王座，也让“斩天”二字成为那个时代最鲜明的杀伐象征。
- **始尊大帝（妖）**——身负极古老的妖族血脉，以《始妖传世诀》统合妖气与万灵之力，并创出【灵魄吞噬术】。本命帝兵【妖魂长鞭】与其道路相合，擅束魂、夺力。成帝后，他推动各支妖族从松散部落逐渐走向共同秩序，其影响更多体现在文明整合，而非单纯征服。
- **斗战大帝（妖）**——天生巨力，自幼便以战斗磨炼自身，最终从妖族古武《天兽之力》中走出一条极端纯粹的斗战之道。本命帝兵【战神巨锤】同样以正面破坏见长。成帝后，他几乎从未停止挑战强者，以一场场胜负建立威名，成为天武时代最著名的妖族战帝之一。
- **普华大帝（冥）**——冥族大帝，修《冥河洗魂术》，一生所学皆围绕生死、魂魄与冥河展开。本命帝兵【冥轮引魂杖】可牵引与拘束亡魂。成帝后，普华一改冥族长期隐于暗处的作风，主动向外扩张，带领冥族夺取多处疆域，开创了冥族历史上少见的强盛时期。
- **白朴大帝（妖）**——被后世视为洪荒十大神兽白泽的再生延续。太初大帝横扫十大神兽时，白泽凭借趋吉避凶与感知天机的天赋提前察觉死局，没有与太初正面决战，而是主动斩断自身完整生命，将绝大部分洪荒本源、肉身与神魂彻底舍弃，只留下不具完整意识的一枚“白云种”。因此洪荒白泽在天道意义上确实已经死亡，并不是靠封印把同一条生命拖到天武时代。漫长岁月后，白云种重新孕育成一个新的完整生命“白朴”，其生命年轮从重新出生时计算，所以仍符合帝路十万岁限制。白朴成长过程中逐步觉醒白泽的记忆碎片、天机天赋与部分本源，最终形成“既是白朴、又延续白泽”的特殊身份，创《白云冥神诀》，并以【天火紫焰扇】证道。与同代诸多以蛮力称雄者不同，白朴更善谋势与布局，常以较小代价取得决定性胜利；成帝后建立白朴寺一脉，晚年飞升仙界，【天火紫焰扇】被留在人界传承。
- **五色大帝（人）**——天武时代末期的人族大帝，出身西龙洲一个以五行术闻名的人族古国。年轻时他并无单一最强灵根，反而因五行彼此冲突长期落后于同辈，最终从“相克亦可相生”中悟出五行轮转之道。帝路争锋时，他最擅长把敌人的攻伐转化、拆解再反向利用，最终以【五色轮】证道。成帝后建立五色神朝，将五行修炼从强调单一天赋改造成可相互转换的完整体系，使大量资质普通者也能找到修炼道路。晚年飞升仙界前把【五色轮】留给五色神朝，成为西龙洲最重要的帝级底蕴之一。
- **避神道尊（人）**——与五色大帝同时代的散修，早年曾与五色并肩游历，后来因道路完全不同而分开。避神认为修士越依赖天机、血脉与外界认可，就越容易被更高存在锁定，因此终生研究“从感知中消失”的大道。他没有参加帝路，而是在五色大帝成帝后主动请其以帝威、天机与五行封锁整片星空，自己则尝试在不正面破阵的情况下脱离所有锁定；历经九日后，他在帝威覆盖之下彻底消失一瞬，由此完成道尊蜕变。本命道兵【避神衣】可遮蔽气息、因果与锁定，但不能让使用者真正脱离天道。五色大帝飞升后，避神又在人界停留数十万年，最终无声失踪；其本人及【避神衣】去向均未详。

**开盛时代**

- **神帝（神）**——天武时代末期，神族因长期封闭与内部血脉之争陷入衰退。神帝出身神域旁系，早年反而长期游历外界，在帝路中以吸收、统合不同神力见长，最终以【神辉印】证道。成帝后，他废除神族部分极端血统禁令，建立允许旁系与外出族人回归的“神庭议约”，使神族重新进入跨域政治；【神辉印】可以汇聚并增幅同源神力，也因此成为神族大规模战阵的最高核心。晚年神帝主动飞升仙界，本命帝兵随行，神族则从此结束最封闭的一段时期。
- **星空大帝（人）**——出身帝落域星族前身的观星世家，青年时期花费数万年丈量八域星路，把大量彼此孤立的古传送阵、虫洞与安全航道整理为统一星图。帝路争锋中，他借星辰定位与超远距离转战取得最终本源，以【周天星图】证道。成帝后主持重建跨域星门体系，并推动各大势力建立第一套长期跨域议事机制，被后世视为归一联盟制度的主要前身之一；星族也因掌握星图、星门与航路迅速崛起，后来成为五会之一。晚年飞升仙界，【周天星图】被他留给星族，成为星族最重要的底蕴之一。
- **储圣大帝（人）**——生于资源衰竭的小世界，早年最擅长的不是爆发，而是把灵力、术法、阵势乃至他人一击长期封存，最终将这条道路发展成“储势大道”。本命帝兵【储圣册】可以把预先积蓄的道力分层封存，在关键时刻连续释放。成帝后，他认为历代强者传承过度依赖血脉与宗门，因而创立帝院的早期制度，允许八域天才以考核而非出身获得高阶传承；同时建立多座跨时代资源库，用于禁区暴动与大灾后的恢复。晚年坐化前将大部分积蓄归还天地，【储圣册】则封入帝院最深处。
- **天秘大帝（天）**——天族出身，自幼能够感知天机留下的“缺口”，却因此发现过度推演同样会反噬天地与修士本身。他以隐藏、整理和切断信息因果的道路证帝，本命帝兵【天秘牒】可以封存天机信息、制造推演盲区。成帝后，天秘大帝没有建立庞大王朝，而是联合天机阁等势力制定高阶推演禁忌：禁止大规模窥探凡俗未来、禁止以天机术长期操纵帝路参与者、禁止直接公开禁区核心坐标。其制度并非人人遵守，却成为后世天机师默认的底线。晚年飞升仙界，【天秘牒】随行。
- **玄武大帝（妖）**——本体为玄甲古龟，并非洪荒十大神兽之一。楚域曾因天鹏大帝留下的“天痕”和历代大战产生大量持续扩张的空间裂口，玄武早年便以修补裂界为生；他把地脉、空间与守御大道合一，最终在帝路中以“守到无人可破”的方式夺得本源。本命帝兵【玄武碑】可锚定地脉、稳固空间并承受大范围冲击。成帝后，他耗费数万年镇压楚域最大的七处空间断层，使大量荒废星路重新开放。晚年将玄武碑留在最大裂口作为镇界核心，自身飞升仙界。
- **青龙大帝（龙）**——出自青龙主脉，却并非当时最受看好的龙族继承人。其大道重“生生不息”而非纯粹毁灭，以木行生机修复龙躯、以连续攻势消磨对手，帝路末期凭极强恢复能力熬过数次围杀而最终证道。本命帝兵【青木龙槊】兼具生机与破阵之力。成帝后，他重新调解五大龙脉长期积累的领地与血统争端，确立五脉共同守护古域核心龙脉的盟约，并把部分亚龙、蛟族纳入外围龙裔体系。晚年飞升仙界前将【青木龙槊】留在古域，使龙族能够长期同时掌握多件帝兵的历史底蕴进一步加深。
- **神赤大帝（妖）**——出身天朝域一个并不起眼的赤羽妖族，早年经历宗族被大型势力征召为战争附庸，因而极度厌恶无休止的族群消耗。他以血气与战意入道，却把“战”理解为让分散者形成共同意志；本命帝兵【神赤战旗】能够凝聚自身妖血与战意，并短时激发相近血脉的潜力。成帝后，他强行终止天朝域持续数万年的多族大战，划定大势力征召附属族群的底线，并推动妖族多个支脉加入归一联盟体系。其晚年在一次魔骨血海暴动中重伤，数万年后坐化，【神赤战旗】由其后裔带离天朝域，现今具体归属不明。
- **地藏大帝（人）**——开盛时代最后一位有完整公共记录的大帝。少年时期长期在帝落域边缘世界修补崩塌地脉，修行核心始终围绕“大地承载万物而不争”。帝路末期，他利用对八域地脉与星辰引力的理解构筑绝对阵地，以【地藏图】完成证道。成帝后最大的功绩是镇压葬神墓地一次几乎波及帝星的暴动，并把墓地外溢的死气导入数百颗荒星，重塑成缓冲带。晚年地藏大帝独自进入葬神墓地最深处，此后再未公开出现；数十万年后其帝威与天道印记彻底从人界消散，说明帝位已经终止，但究竟是飞升、坐化还是在禁区中发生其他变化，至今无人知晓。【地藏图】同样未再现世。

**公开正史帝级存在种族统计**：人族17位、天族5位、妖族23位、神族4位、龙族6位、冥族2位、灵族2位、魔族1位、鬼族1位，合计61位（其中53位大帝、8位道尊）。长生尊的原始种族目前未正式设定，因此不并入公开种族统计；计入其本人后，实际已知帝级存在至少62位。

- **天武时代**：《武帝战典》（武帝，并创"武劫制度"）；《化龙经》（天蛟大帝）；《焚天经》（武凤大帝）；《天儒经》（天儒大帝，以仁、义、礼、智、信构成修炼脉络）；《丈史经》（丈史大帝）；《浮龙无极诀》（浮龙大帝）；《振天无极诀》（振武道尊）；《天道断裂术》（截天大帝）；《斩天破界诀》（斩天大帝）；《始妖传世诀》（始尊大帝，并创【灵魄吞噬术】）；《天兽之力》（斗战大帝所承妖族古武）；《冥河洗魂术》（普华大帝）；《白云冥神诀》（白朴大帝）。天妖大帝未记载功法名，其"狂化"天赋由引爆【万妖幡】散入妖族血脉而来；天鹏大帝、赤凤道尊、龙帝未记载功法名。
- **开盛时代**：未记载自创功法名；神帝、星空、储圣、天秘、玄武、青龙、神赤、地藏八帝以各自大道与本命帝兵留名。
- **特殊传承**：《长生经》（源自仙界，由长生尊执掌并传入人界；本质是吞噬他人寿命转化自身寿命）。

**未以《》标注的帝级术法与天赋**（正文未用书名号、但确属帝级存在所创的传承，一并归入合集）："九尾迷天阵"（天姬道尊，以古妖血脉扰乱天机的迷阵）；"狂化"天赋（天妖大帝，飞升时引爆【万妖幡】将妖灵散入妖族血脉而成，让妖族短时获得洪荒妖祖战力）；"武劫制度"（武帝，要求妖族突破问鼎境需经生死考验的武道考核制度，属制度性传承而非功法）。

**大帝更替规则**：每位大帝寿命大约250万年。通常情况——当世若仍有大帝存活，便不会有人成就大帝，因为天道不会再次释放本源；唯有宇宙中不存在大帝，过数百万年后天道才会释放一缕天道本源，随即展开上万年的帝路争锋，最终大帝诞生，依次轮回。

**双帝时代特例**：通常一世只有一位大帝——当世存在大帝时，天道原则上不会再次释放天道本源。但存在极罕见的例外：天道本身可以在特殊历史节点主动允许"双帝时代"存在。天帝、人帝共治时代就是已知的特殊双帝时代。这种例外由天道本身允许、极其罕见、不能由普通修士主动复制，也不代表一个时代可以无限出现多个大帝。同一时代出现大帝与道尊（排序中同一行出现）则属另一回事——道尊不需要天道本源，说明二者可同时存在：一般是渴望证帝者拼死搏杀最终证帝，后起者奋勇挑战大帝而不死，最终潜力爆发成就道尊。

**大帝差距**：大帝之间亦有差距，最强大帝可称无上帝，公开历史中太初大帝与斗天大帝明确达到这一层次；神凰大帝、人帝等属于无双大帝；再往下为普通大帝，如古元大帝、灭帝等。剑帝早期属于普通大帝层次，但在与唯尽道尊长期争锋后突破至无双大帝层次。天帝与人帝巅峰时期均为无双大帝，自斩帝身后则跌落至“帝落”层次。**神凰大帝在其自身巅峰时代**可称无双大帝第一档，实力无限逼近无上帝；她后来已经飞升仙界，因此不能再写作“当世大帝”。当年三大神尊与神凰交锋时，【太初鼎】凭太初大帝留下的位格与威能，能够对【不灭神羽】形成显著压制。

### 人物传

**长生尊**：来自仙界《长生经》的传人。该经本质是窃取、吞噬他人寿命并转化为自身寿命，吞噬对象必须达到归一境以上，境界不足则几乎无效；长生尊于洪荒时代机缘巧合得到此经。神化时代，他与年轻时的逆天大帝数十次交锋，最终败北，逆天大帝也由此在生死磨砺中创出《逆天决》。

逆天大帝与天尊残留恶念同归于尽后，长生尊以恶念最后一丝生机换得一缕天道本源，并借恶念之力在证帝完成后斩断自身与天道的持续联系。这形成了人界历史上唯一已知的“隐帝漏洞”：**长生尊是真正完成过大帝层次蜕变的存在，因此拥有大帝寿元、帝级本质与一件必然存在但尚未公开的本命帝兵；但天道在其证帝之后无法继续感知其存在，后续大帝更替也不会把他视作“当世仍有大帝”。**因此他不进入公开的53位大帝谱系，也不会阻塞后世帝路，这解释了“长生尊早已证帝”与“后世仍能不断诞生大帝”之间的矛盾。

拓荒时代，长生尊将《长生经》给予天帝与人帝。两帝为追求长存主动自斩帝身，跌落至特殊绝巅层次并隐入禁区，与长生尊并称三大神尊——天神尊、人神尊、长生神尊。神凰大帝之变中，三大神尊合力且由长生尊祭出【太初鼎】，才最终逼退巅峰神凰；之后三大神尊自封百万年。

随着时代推移，单纯吞噬归一强者已经无法满足长生尊。归一寿命与生命本质远低于大帝，而一次吞噬大帝所获得的不只是寿命，还包含更高层次的生命与大道积累。自太古时代起，长生尊逐渐把目标转向当世大帝。至今他已吞噬过数位大帝的寿命与部分本源，实力无限接近无上帝，却仍未真正跨入无上帝层次。由于天道无法追踪他，公开势力也不知道“长生尊仍活着”这一事实的完整真相；他与天帝、人帝的隐秘联盟依旧存在，只是三者并非始终目标一致，更多是基于长生与躲避天道的共同利益维系。

## 当前世界状态

**世界层面**：当前处于开盛时代后期，上一位公开大帝为地藏大帝。地藏大帝的帝威与天道印记已经从人界消散，因此**当世公开状态为无帝**；但天道尚未正式释放新的本源，人界正处于“帝位已空、帝路未启”的漫长窗口。这个阶段没有固定倒计时——历史上从旧帝位终止到下一缕本源出现，间隔可达数百万年，因此所有顶尖势力都只能判断“下一次帝路越来越近”，无法知道准确年份。

当今宇宙最强公共势力仍是归一联盟，存在数百万年并近似承担跨域秩序中枢职责，五会实际掌握最大话语权；全宇宙约230位归一强者，其中联盟约160位。帝落域仍是最古老、最强盛的域，帝星五洲则是全宇宙顶尖势力最密集的单一古星之一。古藏大帝奠定了妖族在帝落域的长期优势，道天大帝则奠定了五会中人族三会的早期根基。

**公开世界不知道的状态**：长生尊依旧存活，但因其与天道的联系已被斩断，既不会让帝路停摆，也不会被归一联盟的常规天机体系发现；天帝、人帝仍以帝落层次隐于暗处。三大神尊因此构成当前世界最大的隐藏变量。
