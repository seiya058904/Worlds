# 人界

> 九族共居八域，修行即宇宙的度量衡；六十一尊公开帝座与道尊交替于数千万年史册，而三清往事与仙界，还在天道更上层。（世界名为暂定名，取自原始便签的"人界篇"。）

## 世界速览

人界是一片以修行为骨的宙宇。生灵自凡胎起步，循练气、筑基、凝丹、元婴、化神、洞虚一路攀至问仙；待踏入归一，通往至高处的道路便一分为二：一途在半道以下入帝路争锋，夺天道所释的一缕本源以证大帝；另一途越过半道、绝巅，不假天道权柄，纯凭己身大道强行破境，成就道尊。大帝与道尊并立为人界绝顶，正常寿数皆约二百五十万年。大帝之位受天道本源所限，通常当世无帝时，天道方会释放一缕本源，开启绵延上万年的帝路杀伐，最终诞生新帝，依次轮回。

宇宙横分八域。帝落域最古，帝迹与巨擘云集；古域为龙族祖庭；九星秘境域则是灵族根本。人、妖、龙、天、灵、神、魔、鬼、冥九大族系散居八域星海。当世最庞大的公共权柄归于延续数百万载的"归一联盟"——全宙宇约二百三十位归一境大能中，约百六十人挂名盟册，长期承担宇宙顶层秩序中枢之责；盟内最高话语权则由"五会"（李族、神武族、古夜族、帝兽族、星族）把持。

自太初大帝扫平洪荒十大神兽、开启神化时代以来，历经拓荒、太古、天武、开盛五世，**公开正史共录六十一尊帝级存在——五十三位大帝，八位道尊**。每位大帝各铸一件本命帝兵，每位道尊各成一件本命道兵，留下的帝经、道统与太初古矿、堕仙界、九龙谷等九大禁区，至今仍是八域生灵仰望与忌惮的旧迹。而在正史六十一尊名录之外，另有一位自洪荒活到今日的隐秘大帝——长生尊。他于神化末年窃本源证帝，旋即斩断天道感应，数千万年来游离于一切规则与道统之外，专以吞噬高阶修士乃至大帝寿元延命。计入此人，人界实际已知的帝级存在至少为六十二尊。

## 正式设定

### 天地与宇宙

人界之外另有仙界。三清时代的旧事属仙界篇：昔年元始天尊与道德天尊死战，打得仙界崩坼、大道法则溃散；灵宝天尊居中止戈后，元始天尊劈宙宇为天、人两界，自赴九界深渊镇守残破法则，永世不得擅离；道德天尊则身化人界天道，重塑法则后当场兵解，皮囊化灵气、神魂化大道，枯寂的人界始有生机；轮回天尊为弹压乱世创立天庭，定九天十地、九大天尊、十大界域与三十六地尊之制；灵宝天尊则携门人自辟灵宝天界，与仙界断绝接壤，万世不出。三清以上皆归仙界史册，人界正文自洪荒时代起笔。

**八域**：

"域"系宇宙级地理疆界，非止一星一陆。每一域皆囊括恒河沙数的星辰、生命世界、折叠秘境与死寂虚空。凡俗与寻常修士终生困守一星；真正稳定的跨域通行，唯有仰赖大型星门、远距古传送阵，或由高阶大能以肉身横渡虚空。

| 域名 | 整体定位 | 主要特征 |
| --- | --- | --- |
| 化心域 | 中等强域 | 星辰疏密悬殊，多上古心神、幻道与神魂遗迹；因无尽深渊横亘域内，深空险道与封锁星区极多。 |
| 九星秘境域 | 较强 | 九片巨型星群拱卫中央灵能漩涡，系灵族主要根据地；灵能冠绝八域，空间秘境与灵潮暴动亦最频仍。 |
| 帝落域 | 八域之首 | 传承最古、顶尖道统与帝级遗迹最密，帝星为其政治与修行天枢；太初古矿、不灭凤巢、葬神墓地三大禁区皆聚于此。 |
| 天朝域 | 新兴强域 | 旧门阀根基较浅，新王朝、新宗门与跨族势力兴替极快，兼并最烈；魔骨血海是悬于域内的最大凶患。 |
| 划凡域 | 相对弱小 | 高阶灵脉稀薄，凡俗世界与低阶修士人口却极浩瀚，系八域基础物资与商路最稠密之地；顶层大教对基层星辰反而鞭长莫及。 |
| 飞仙域 | 老牌强域 | 古宗林立，飞升传说与遗迹众多，各大老牌山门疆界分明；因堕仙界在侧，历来是考据帝法与禁区遗产的重镇。 |
| 楚域 | 中等强域 | 古来屡遭空间崩裂与帝战余波重创，断绝星路、时空异常与阴灵鬼物随处可见；九幽仙宫坐落于此。 |
| 古域 | 老牌强域 | 龙族根基所在，遍布龙脉、古星与血脉祖地；五大龙族支脉共掌域内秩序，对外来势力涉足核心星区禁令最严。 |

八域从无一统的凡俗皇权。归一联盟虽居顶层协调、仲裁与联合行动之位，却无统辖各域的天然皇权，重大行动亦须经联盟内部表决；绝大多数星辰、神朝、宗门与世家皆高度自治。宇宙顶层有公共盟约，地方星域照常伐山破庙、宗门争霸，二者并行不悖。

**帝星与帝落域五洲**：帝星是帝落域最庞大的一颗超级生命古星，亦是全域道统最密集的枢纽。旧志习称其核心区域为"五洲"——此乃古称沿袭，既非帝星仅有五块陆地，亦非帝落域只此一处文明中心。五洲主要坐落道统如下（统一写作"洲"）：

- **南淞洲**：宋王府、石林族、鬼魅族、南妖族、普华天龙寺♢、万仙阁♢、重阳宗、古罗寺、碧螺天、复光宗、古仙神朝♢、南海蛟族
- **西龙洲**：古佛宗♢、青山派、沙龙族、古魔宗、五色神朝♢、西墨族、普罗神朝、盗月宗、满阳楼、九部古妖族、盘龙族、焦山派、白朴寺♢、古龙寺♢、阳神教
- **北烟洲**：万盛天国、化天紊尊族♢、长明派、古神族♢、生死天、北海蛟族♢、仙乐楼、万妖阁♢、神牛族、古鹏族♢、黑龙族、炎王教、封神宗
- **东华洲**：飞仙教♢、尸谷♢、毒宗、绝情谷、浩气宗、九岭部、天山峨、清墨教、阴宗、邪龙族♢、古泉池、凤羽教、灵族支脉♢、兽谷、极天妖族♢
- **中洲**：万妖武殿♢、神时阁♢、古藏♢、道一宗♢、万妖宗♢、帝院♢、始族♢、神组♢、星族♢、天机阁♢、李族♢

名录中标"♢"者，仅代表"顶尖势力"层级，彼此并非同盟；未标♢者亦未必弱小——某些古脉或握有沉睡帝兵，或藏有自封的半道老祖，又或背靠历史盟约，实际威慑力往往超出常规纸面评级。

**九大禁区**（括号内为所处域）：太初古矿（帝落域）、堕仙界（飞仙域）、九龙谷（古域）、不灭凤巢（帝落域）、无道死地（九星秘境域）、九幽仙宫（楚域）、无尽深渊（化心域）、魔骨血海（天朝域）、葬神墓地（帝落域）。

"禁区"乃后世对九处至高绝险之地的统称，其起源各异：或为大帝亲手开辟的试炼道场，或为远古遗留的生命禁地，或为帝战、封印与异常法则累世淤积而成的灾区。禁区亦非踏入即死的铁板绝境，其内部空间与生态层叠极深——外围常年有散修冒险者、宗门据点与黑市交易往来；中层便足以吞没寻常高阶修士；唯有最深处的核心绝地，潜藏着足以格杀归一乃至威胁半道强者的凶险。

太初古矿由太初大帝汇集诸禁区收获而辟，初存【太初鼎】、《太初法》与万千珍宝，内里太初道文自行流转，原为留待后人的试炼与传承之地。然神化之后，长生尊曾暗入太初古矿取走并使用【太初鼎】；只因公开世界无从知晓这段隐秘，后世诸多古籍仍沿袭旧闻，将【太初鼎】记作"长眠于太初古矿深处"。按真实状态论，【太初鼎】早已被取离古矿。

及至拓荒时代，斗天大帝又将《斗天九法》分别布入九大禁区，使每一禁区各对应九法中的一脉传承或试炼。九大禁区现况如下：

**修炼共通规则**：

- **练气三途**：练体、练心、练魂乃练气期最常见的三门起步路数，而非永世互斥的职业。修士多取一途为主、余二途为辅；越往高境，肉身、神魂、心境三者越难割裂。
- **寿命含义**：表列寿数皆指无沉重道伤、无特殊血脉亦未服延寿奇珍时的自然大限。高阶修士以秘法封印或沉眠，虽可大幅压低生机流失，却既不会凭空增长境界，亦无法无限规避天道对真实骨龄与生命本质的勘定。
- **越境原则**：低境修士尚可凭体质、古经、秘术、杀阵或帝兵越境伐敌；境界越高，跨阶越难。一入归一以上，高下全系于大道完整度，寻常外物堆砌已极难抹平鸿沟。
- **帝路年龄**：帝路"十万岁以下"之铁律，以天道识别的**当前完整生命年轮**为准。自封沉眠百万载者，年轮照算，断无入路之理。古今唯极少数真正完成"上一世生命彻底终结、以全新生命重降于世"的涅槃或再生者，方会开启新的生命年轮；此等重生必伴随旧躯、旧修为乃至大半记忆的彻底焚毁，绝非低代价续命之术。
- **半道以上不得争帝**：半道及绝巅修士的大道已高度自成体系，与承载人界天道权柄的天道本源天然排斥。若自毁道基退回争帝，无异于自断生路，史册上从无稳定成例。

### 功法等级与传承规则

人界诸般功法、秘术、神通、炼体法、神魂法与阵道法门，皆按其**理论上限、法则完整度、大道承载力与传承难度**划分为八阶。品阶衡量的是法门本身，而非修习者当下战力；低境修士纵得高阶经文，亦只能发挥自身境界所能承受的一隅。

| 品阶 | 大致定位 | 常见特征 |
| --- | --- | --- |
| 凡级 | 基础启蒙法 | 专供凡胎强身及练气、筑基早期阶段行气，结构浅白，流传最广 |
| 灵级 | 正式修士主流法门 | 可稳固塑造灵力周天、丹田与基础术法体系，中小宗门立宗常见 |
| 玄级 | 中阶宗门核心内传 | 始系统涉及神魂、元婴、特殊体质与成套战斗体系，通常秘不外传 |
| 地级 | 高阶势力镇宗传承 | 已能承载空间、领域、虚实变化等高阶法则，足充大型宗门镇派功法 |
| 天级 | 顶级势力主干道统 | 可一路支撑高阶修士参悟法则、凝练己道，唯大势力核心真传得窥全本 |
| 圣级 | 帝级以下最高常规品阶 | 已触及大道本质，足作归一境巨擘的核心依仗；完整圣级法极罕，一部便是一方顶尖势力底蕴 |
| 帝级 | **人界常规体系最高品阶** | 承载大帝或道尊功成后的核心大道、帝道体悟或成道体系。完整帝经可直指人界绝顶，然仍须自过天道本源、帝路争锋或道尊破境之关 |
| 仙级 | **人界体系之外的特例** | 超出人界生灵所能自创与常规评定的范畴。当世唯一明确确认的仙级功法，唯有源自仙界的《长生经》 |

**传承与修持通则**：

- **品阶与战力非机械绑定**：天纵之才可凭较低品阶法门一路推演至高境，高阶大能亦可将粗浅法门重炼升华；反之，境界不足者纵怀抱帝经，亦断无直接发挥帝级威能之理。
- **帝尊所创非必帝级**：大帝、道尊一生随手创出的筑基篇、秘术、阵图与辅助小法不知凡几，多属天、地、圣级；唯有真正熔铸其核心大道与至高体悟的主干经文，方列帝级。
- **帝级传承的载体与残篇**：大帝或道尊成道后，通常会将毕生核心道路整理为至少一门帝级传承。其载体或为成套经卷，或为帝兵内壁的大道烙印、血脉传承、秘境道碑，甚或仅是一段非文字可录的"帝意"。同一门高阶功法在后世常分化为原典、真传、分卷、抄本、残篇与改编本；品阶以完整形态为准，残缺帝经往往仅能发挥天级甚至更次之效。世间诸多号称坐拥帝法的宗门，库中所藏泰半仅是一卷分篇或一段残存帝意。
- **帝经不造现成大帝，抄字亦难抄法**：帝级功法虽能指引前人通天之路，然证大帝仍须夺天道本源，证道尊仍须破己身大道。且圣级以上、尤以帝经为最，核心处皆含大道意境与神魂烙印；凡俗纸墨仅能摹其"字"，摹不出其"法"，故数百万年来帝经从未因一时外传而泛滥八域。
- **兼修之忌**：低阶法门改修或兼修尚易；越往高境，功法对肉身、元神与大道的塑造越深，强行兼修极易引动道基相冲。古今能将诸般高阶道路熔于一炉者凤毛麟角，斗天大帝熔历代帝法为《斗天九法》，乃史册仅见的极端孤例。
- **仙级孤例《长生经》**：源自仙界，位格超出人界品秩之外。其超格之处不在正面攻伐压过一切帝法，而在直接干涉寿元与生命本质。此经使用门槛极严：**被吞噬对象须至少达归一境以上**，问仙以下生灵几无有效寿元可榨。

**归一三阶段**：归一境内部按大道熔炼深浅分为三阶。**化简**为初阶，将诸般驳杂法则化繁为简、融会贯通；**合一**则令诸法则彻底并入己身大道，战力较化简暴涨数倍；**无瑕**乃归一极境，所修大道圆融无缺、不留微瑕，至强者已可与半道大能正面短暂交手。

**半道**：帝尊之下的极境。古往今来当世并存的半道从不超过五位。十之八九的半道老祖皆将自身封印以止住生机流失，长年镇守顶尖道统核心祖地数百万载；非遇灭族覆宗之祸，绝不轻出。

**绝巅与帝落**：绝巅乃距一步登天仅隔薄纸的玄妙境界，周身气息几与大帝或道尊无异，唯生命位格尚未迈出最后一步；三位绝巅联手，战力堪比一尊普通大帝。另有两类至强者会跌入此境：一是自封过久、生机枯竭的大帝或道尊，境界随之滑落至绝巅；二是主动自斩帝身的大帝、自斩道果的道尊，虽同落绝巅，战力却远迈寻常绝巅，世称**"帝落"**——其战力可无限逼近普通大帝，然自斩不可逆转，欲返至高之位，须重历大帝或道尊的完整晋升劫数。

**大帝与道尊**：这片宇宙的至强者。大帝内部由低到高分为普通大帝、无双大帝、无上帝三档；道尊的常态战力下限已贴近无双大帝，然稽考已知八位道尊，尚无一人达到真正的无上帝层次（此乃历史实录，非限制后世的天道铁律）。

大帝与道尊系两条截然不同的登顶之路。境界表（归一→半道→绝巅→大帝/道尊）仅标示位格高下，**半道与绝巅绝非证道大帝的必经台阶**：

- **大帝路线**：核心在于夺得一缕天道本源。常例为：境界至少达问仙、半道以下，且天道年轮不超过十万岁，入帝路争锋夺得本源，一步证道大帝（偶有如夜帝趁太初古矿暴动窃取本源者，依人物实录为准）。
- **道尊路线**：不假天道本源。纯凭自身大道、生死大悟、大毅力、大机缘，或在与当世大帝的殊死搏杀中不死而强行破境。半道、绝巅更贴近此路脉络，亦非死板公式。

**帝兵**：与大帝帝位绑定的唯一至高本命兵器，与道兵并列为人界器物之巅。

- **本命形成与归属铁律**：每位大帝必有且仅有一件本命帝兵，多在证道前后由伴随其大道与生平最契合的兵刃升华而成。**本命归属永世绑定其大帝原主**；后世纵历经传承、夺取、借用或由其他大帝执掌（如长生尊取用【太初鼎】），亦绝不改变其本命归属。
- **使用与激活三档**：
  - **普通使用**：理论上任何生灵皆可引动帝兵最表层的一缕威能。然低境修士往往仅能换取瞬息护体、威压或一击之力，旋即因法力、肉身与神魂难以承受而被迫中断；唯有自身境界足够高深者，方能将普通使用常态维持在迫近归一境的水准（仍不足以击败状态完好的归一强者）。
  - **正式激活**：至少须达**归一无瑕境**。无瑕强者正式激活，约可催发帝兵一成威能，战力堪比**半道**。
  - **完美激活**：唯**半道及以上强者**可为。约可催发帝兵三成威能，战力远超寻常半道，足以与**绝巅**存在正面交锋。
  - 普通使用、正式激活、完美激活三档界限分明，不可混同。

**道兵**：与道尊大道绑定的唯一至高本命兵器，与帝兵同处人界器物绝顶，无天然高下。每位道尊必有且仅有一件本命道兵，故史册出过八位道尊，便曾现世八件本命道兵。其强弱视原主道行、器物特性、执掌者契合度与当场状态而定。

- **血脉死锁**：道兵完整沿用帝兵的"普通使用（近归一）—无瑕正式激活（半道级）—半道完美激活（抗衡绝巅）"三档机制，唯独多出一道铁槛：**唯有与原道尊血脉相通者方能真正催动道兵**；外姓异血纵夺得道兵在手，亦调动不了分毫威能。
- **存世数量**：当世公开资料确认仍留存人界的道兵仅余三件——**【悟道剑】、【幽冥镜】、【天机双生佩】**。其余道兵或随主飞升，或去向未详（去向未详仅指公开史册失载，非断言其已毁灭或离界）。

**飞升兵器去留与帝位终结之判**：大帝或道尊飞升仙界时，可自择携本命兵器同行或留镇人界（史文明载留下者留人界；明载飞升而未言留兵者，默认随主飞升；人物结局与兵器去向皆失载者，记作"去向未详"）。凡史书仅载某位大帝"失踪/去向未详"，只代表后人不知其终局；**只要后世天道再度正常开启新帝路，即铁证上一任大帝在天道层面的帝位早已终结**（或飞升、或陨落、或自斩跌落），绝无"仍以完整大帝位格暗藏人界而天道照发新本源"之理。

**帝路争锋**：当世若仍有大帝在位，天道绝不释放本源，世间亦无人可证新帝；唯宇宙帝位空悬、再历数百万载岁月沉淀后，天道方会释出一缕本源，掀起长达上万年的帝路血战，终诞新帝，循环往复。入路铁槛：天道年轮不超过十万岁，境界在问仙（含）以上、半道以下。（双帝时代系天道主动允许的孤例，详参下文"大帝更替规则"。）

**斗天九法**：拓荒时代斗天大帝博采古今帝法所创的《斗天九法》，九法各臻一域极致，九法合一可证无上帝。后世大帝多曾身兼数法，唯斗天大帝一人达成九法合一。九法后被其分置九大禁区，每一禁区各藏一法之传承或考验（具体对应归属未详）：

- **斗仙**（破限之秘）——榨尽潜能至极限，短暂冲破境界枷锁跨阶伐敌；身陷绝境时威能尤盛，系九法中"以下伐上"之冠。
- **斗神**（攻伐之秘）——演化诸法、以战养战，临阵将所见功法神通拆解重构为己用，系九法第一攻伐之术。
- **斗鹏**（极速之秘）——取大鹏振翅意，身法快至极处可短暂擦触时间领域，于敌手念头未起前决出攻防。
- **斗破**（爆发之秘）——瞬息引爆自身战力、数倍叠加倾泻；负荷酷烈，不可久持。
- **斗图**（阵道之秘）——以天地山河为阵图布下绝世杀阵，阵法与己身大道合一，一人即成大阵。
- **斗龙**（驭物之秘）——以龙威驭使万物，夺兵、御器、镇压外物，控兵之术冠绝古今。
- **斗身**（不灭之秘）——锤炼肉身至近乎不灭，受创极速愈合，纵余一息尚存亦可重塑肉身。
- **斗转**（推演之秘）——推演万法流变，洞穿敌手破绽与战局走向，料敌机先。
- **斗灵**（元神之秘）——专修元神神识，秋毫毕察，可预知凶险、感应天机微澜。

### 种族

世间主体文明与生命谱系共分九大种族：人族、妖族、龙族、天族、灵族、神族、魔族、鬼族、冥族。至于星海中浩如烟海的古兽、异种、混血、灵体与边鄙部族，悉数依血脉与道统归入最贴近的九族体系。

**人族**：分布最广、总体人口最众。单论先天血脉，人族常逊于神族、龙族等先天强族；然个体资质跨度极大，繁衍极快，对诸般功法、法宝与礼法制度的兼容性冠绝八域。人族最擅以宗门、神朝、家族、书院与商盟织就庞大社会，故跨域制度、通用法门与巨型星城多带鲜明的人族印记。唯人族内部从无天然归心，王朝、宗门与世家间的同族倾轧，往往比异族征伐更为频仍。

**妖族**：非单一血脉，凡草木、飞禽、走兽、异兽乃至天地精怪启灵开智、立下独立修行传承者，皆归妖籍。妖族内部自寻常启灵兽类至洪荒遗种落差极大，高阶强者尤赖血脉、悟性与后天返祖蜕变；化形为人仅系常见习俗而非铁律。因支脉繁杂，妖族总体势大却天然松散，太古古藏大帝定妖文、天武武帝立万妖武殿，皆在试图拧合这盘散沙。

**龙族**：血脉最古的独立强族，不入妖籍，世代据守古域。每一时代至少有一尊半道"守护龙"坐镇。龙族几大主脉的底蕴冠绝寰宇，一脉往往能同时执掌三四件乃至更多帝兵。太古祖龙大帝一统天下龙族，划定青龙、应龙、烛龙、苍龙、玄冥龙五大主支脉；至于蛟族、亚龙与混血龙裔能否算作龙族核心，悉依五脉各自的血统家法裁定。

**天族**：与神族并非同族。天族生而敏于天地法则与天象流变，部分嫡血降生时自带"天纹"，于阵道、天机、空间、雷霆诸途得天独厚。族内重血统谱系、契约与礼序，却不似神族那般闭锁；自太古古仙大帝重订法典后，天族彻底建立起独立于神族的修行与政治传统。其短板在于过分依仗天地环境，一旦陷入绝灵死地、法则紊乱区或无道死地，受制尤深。

**灵族**：诞于宇宙初开的九星秘境域中央灵能漩涡。严格意义上的"纯血灵族"常年仅维持在数百人之数，域内人口浩瀚的灵裔、附属家族与灵能生命皆不入纯血正册。纯血灵族天生可操纵天地灵能，术法诡谲多变；凡境自然寿数约千年，一旦踏入半道，因生命构造特殊，**寿数可达约一千万年**（常族半道仅百万年）。族内以家族与九大灵脉为骨，平日松散竞争，遇外侮则顷刻合流。那九大灵脉系古灵大帝飞升前分化己身灵体所留；化灵大帝则曾自碎本源灵核，修复几近崩解的灵能漩涡。

**神族**：自人界初辟便存世的稀少强族，平均先天资质居九族之冠。其核心祖地统称"神域"，多由浮空神城、神山与封闭小世界构筑。族人降生常伴神力异象，对神力与高阶神术领悟极快；代价则是血脉繁衍艰难、人丁稀薄、风气高度封闭，历来靠极少数绝顶强者撑起全族威权，直至开盛时代神帝立"神庭议约"方解闭锁之弊。

**魔族**：以强横魔躯、魔血与极端绝地适应力闻名，天朝域魔骨血海周边为其最大聚居地之一。魔修多走肉身蜕变、吞炼、血契与雷劫淬体之路。"魔"在人界系生命形态与修行体系分类，绝非天然邪恶之代称——魔族内部照样立有严整王朝、守序宗门与部族；唯部分古魔经文需吞噬血肉、魂魄或掠夺天地生机，故与外族积怨极深。

**鬼族**：由阴灵、魂体、时空残灵及死后经特殊条件稳定转化的生命构成（寻常生灵死后亡魂不会自动沦为鬼族，须合特定环境、功法或本源方可凝成稳定自我）。鬼族无常人血肉之躯，专擅神魂、阴气、诅咒与时空秘术；九幽仙宫与葬神墓地皆为其历史核心险地。

**冥族**：太古时代由神冥道尊创立的独立生命谱系，与鬼族截然有别。冥族具实体冥躯与可延续血脉，本源亲近黑暗、生死与冥河之力，无须以亡魂形态存世。全族长年潜行于宇宙暗处，精于隐匿、替死、魂魄与生死秘术。太古古月大帝陨落后，【葬月轮】与月光本源落入冥族；神冥道尊本命道兵【幽冥镜】封存月光本源，每逢特定月相便引动"阴阳暴动"，至今仍是冥族最核心的修行盛事。

**十大神兽**：凤凰（神凰大帝）、麒麟、梼杌、獬豸、犼（九玄大帝）、重明鸟、毕方、饕餮、白泽（白朴大帝）、祖龙（祖龙大帝）。洪荒时代万族争锋，演化万年诞出此十大神兽族群，分据星海、莫能相下；余族皆在夹缝中求活，人族更沦为诸强族偏爱的口粮，濒临灭绝，直至太初大帝横扫十族方终结洪荒。

### 势力

**归一联盟**：

人界延续岁月最久、覆盖星域最广的顶层联席组织，亦是当世公认的宇宙第一政治体系。

全宇宙约二百三十位归一境大能中，约一百六十位拥有归一联盟成员身份；联盟常年掌控十余件帝兵（多数由五会及核心巨擘保管或执掌调用权，本命归属仍系历代大帝原主）。

然归一联盟并非统辖八域的中央帝国，亦无直属疆土與基层官制。那百六十位入盟归一，绝大多数首先系自家神朝老祖、古族族长或大宗太上，其次方领联盟席位。联盟之设，源于高阶道统对宇宙失控的共同忌惮——当禁区暴动、帝兵全面复苏、半道火并或跨族灭世大战超出一宗一族所能收拾之界，八域顶层必须有一张能坐下来谈判、分摊代价与联合出兵的圆桌。至于地方星辰的王朝更迭、宗门夺矿、世家吞并，甚至两名联盟长老各自背后的道统在星外杀得尸横遍野，联盟一概不问。在长老院里，两家疆域正在死战、双方老祖却于三日后同席表决另一桩跨域议案，乃是司空见惯之事。

**联盟四层架构**：

- **外门执法**：常设直属班底，主理据点维护、传讯、日常核查及普通已决事项交办。成员多为极有希望踏入归一的半步巨擘，间有少数初入归一者，系盟内最接近"直属部众"的一群人。
- **内门执法**：清一色资深归一境强者，专司跨势力大案查办、高阶冲突调停与长老院决议的强行落地，对联盟本体的身份认同远高于寻常挂名成员。
- **长老院**：联盟最高议事中枢，定员常年维持在五十席左右，入席者至少达**归一合一境**。席位格局历来稳固：**五会常年占去约三十席**；龙族、灵族、冥族、神族等强族与巨宗共占约十席；余下约十席留予无大势力背景的顶尖散修与中立名宿。
- **联盟领袖**：每万年推举一任。执掌召集长老院、发起议案、协调诸方及调度联盟直属资源之权。然领袖绝非宇宙皇帝——凡涉重大军事与制裁，领袖不得独断，悉依长老院表决结果行事。

**表决铁律与五会博弈**：

归一联盟最根本的制度与掣肘，皆在**"大事必经长老院投票"**。凡正式制裁顶尖势力、对归一强者动用强制手段、以联盟整体名义参战、干预大型种族火并、大举调拨盟库、集体请动帝兵、处置半道与绝巅级灾变，皆须提交长老院表决；议案越近全面战争或动用帝兵等不可逆之举，所需共识门槛越高。

盟内权柄最重的五大政治集团合称**"五会"——李族、神武族、古夜族、帝兽族、星族**。五会凭族内深厚的归一数量、帝兵储备与庞大的附庸盟友网，握有长老院六成席位，任何大案皆难绕开五会；但五会彼此同样充满利益倾轧甚至世仇，绝非同气连枝的铁板。

由此衍生出联盟**"潜在实力无敌、实际动员视共识而定"**的铁律：
- 当祸起盟外（如禁区大暴动可能席卷八域、或有失控绝巅无差别屠戮各族），危及所有顶层势力根本，长老院瞬息便能高票合流，百余位归一与十余件帝兵倾巢而出，八域之内无任何单一势力可抗衡；
- 当战火烧在盟内大族之间（如李族与另一顶尖世家全面开战），双方各自串联长老院盟友否决提案，五会分裂、强族中立、散修避嫌，议案便无法过关。此时联盟只能束手旁观，任由各势力私下站队或调停，不得冠以"归一联盟介入"之名；即便某项议案勉强低票过关，若赞成者出工不出力，实际能调动的也仅有内外门执法与少数派系兵马。

简言之，归一联盟从不妄图消灭八域的战争；它唯一死守的，是防止某一场局部火并失控为拖垮整个八域顶层道统的灭世浩劫。**联盟的雷霆之威源于顶层共识，其政治僵局亦同样困于共识。**

**大势力评级俗例**：凡有一位归一强者坐镇，即称"大势力"；常年有至少三位归一强者坐镇，通常视作"顶尖势力"（帝兵、半道老祖或上古盟约可令实际威慑超出纸面评级）。

### 普通社会与日常规则

大帝、禁区与长老院高悬于星海顶端，而八域绝大多数生灵的一生，皆在凡俗疆土与低阶修士社会中运转：

- **社会组织**：凡人王朝、城邦、修真宗门、世家、部族、商会与书院交错并立。一颗生命古星或由单一皇朝统御，或由数家宗门与俗世国度分治，八域并无划一模板。
- **修炼教育**：低阶吐纳法门并非绝密。在多数成熟生命世界，练气与筑基阶段的基础功法皆可通过宗门、家族、军伍、书院或坊市习得；真正拉开云泥之别的，是玄级以上功法、灵脉资粮、名师指点、先天体质与秘境试炼资格。
- **通用货币**：凡俗通行金银楮币；修士间以**灵石**为硬通货，按纯度与灵气盈亏分级，各地俗称纵有不同，跨域大商会皆有统一定价折算。一入归一境以上，寻常灵石便难入法眼，交易泰半转为稀有神材、法则结晶、帝遗线索或禁区护道名额的以物易物。
- **交通**：星内或小世界仰赖飞舟、灵兽坐骑与短距传送阵；跨星系需乘巨型星舟或借星门通行；跨域星门则收费高昂且尽为大势力把持。归一强者虽可肉身横渡虚空，亦非瞬息可达八域任何角落。
- **通讯**：近距用传讯符、玉简、神念法器；跨星域赖大型传讯阵与商盟中继节点。星途越远、环境越险，音讯迟滞越甚；禁区与法则乱流区更会彻底截断传讯，故高阶修真界照样常年存在严重的"信息差"。
- **法律与秩序**：地方律令由当世皇朝或驻地宗门自定；跨域与顶层争端由归一联盟议处。高阶修士固然能以伟力强破地方规矩，却也要掂量由此招致的更强道统追杀、商盟资粮封锁与盟约反噬。
- **人口比例**：凡人与练气以下生灵占八域人口绝大多数，越往高境越如金字塔尖收束。全宙宇归一强者不过二百三十人上下，寻常修士终其一生亦难亲眼得见一位归一，遑论大帝与道尊。

### 历史

**时代划分**：超时代、鸿蒙时代、乱神时代、三清时代（以上四代属仙界篇）、**洪荒时代、神化时代、拓荒时代、太古时代、天武时代、开盛时代**。

**洪荒时代**：人界初辟时宇宙空荡、法则尽失，赖道德天尊兵解化身方复生机。首纪为洪荒时代，万族茹毛饮血，演化万年诞出十大神兽族群，分据星海、莫能相下；人族沦为诸强族偏爱的血食，几近灭绝。直至万载岁月流转，天地灵气渐趋饱和，人、妖诸族陆续修出高境强者，始能与十大神兽分庭抗礼。

**神化时代**：以人族诞生人界第一位真正的大帝——**太初大帝**为界碑。太初大帝铸融合十大兽族血肉的帝兵【太初鼎】镇压人族气运，横扫十大神兽（部分神兽族群被打得仅余零星血脉），终结神兽霸权；复独行宇宙万年，孤身踏入诸禁区，杀得禁区之内再无禁忌敢露头。晚年他感应天地法则排斥、知飞升仙界在即，遂聚诸禁区收获开辟太初古矿，将【太初鼎】、《太初法》与万千珍宝封入矿底，旋即不知所踪。

**历代帝级存在年代记**：
以下录公开正史谱系，共 **61 尊帝级存在——53 位大帝、8 位道尊**。**长生尊因证帝后当场斩断天道联系、从未录入公开帝谱，故不计入此 61 尊之内；若合并隐秘历史，人界已知至少出过 54 位大帝、8 位道尊，共 62 尊帝级存在。**（括号内为种族。）

**神化时代**

- **太初大帝（人）**——神化时代之始，人界开天辟地第一位大帝，后世尊为古今第一尊"无上帝"。洪荒末世，他执【太初鼎】横扫十大神兽，将濒临断种的人族拉出血食深渊；成帝后独行八域、踏平禁区，以一己之力重立万族对"至高者"的敬畏。飞升前夕辟太初古矿，封【太初鼎】与《太初法》于极深处，自此渺然无踪。
- **混沌大帝（神）**——神族出身，帝路横推无败，终以混沌体证道。所创《混沌战决》霸烈绝伦，因体质门槛过苛而另立混沌圣堂择徒；后自太初古矿得窥《太初法》，返本归元，推演出万族皆可入门的筑基总纲《天元法》，泽被后世千万载。本命帝兵【混沌战甲】，晚年飞升仙界。
- **道衍大帝（妖）**——本体为一株仙草。平生罕见征伐，唯以传道点化留名：成帝后创《锻灵法》《启灵法》，复著核心传承《帝经》三篇。门下九位最强亲传号"九天战神"（后世所谓"九神合一可屠帝"纯属夸饰，非真实境界换算）。晚年辟道衍界，将道统殿堂与《帝经》终篇藏入混沌，人与本命帝兵【道衍叶】皆自此下落不明。
- **逆天大帝（人）**——起于乱世，一生皆在与既定命数死磕。少时与暗处猎命的长生尊交锋数十场，于生死一线间悟出《逆天决》反败为胜；成帝后发觉三清时代遗留的天尊恶念正侵蚀人界天道，遂提本命帝兵【逆律剑】孤身决战。是役几将恶念彻底斩灭，自身亦肉身崩解、神魂俱焚；【逆律剑】自此遗落虚空，去向成谜。

**拓荒时代**

- **天帝（神）**——神族贵胄，却主动自毁先天神体，苦熬千年重炼混沌体，并自混沌圣堂习得《混沌战决》。在帝路前列与人帝由生死宿敌打成知己；待人帝先一步得本源证道后，天道竟于罕见节点主动释出第二缕本源，助天帝于混沌中同步证道，造就史册最著名的"双帝时代"。两帝合著《天人经》，共治宇宙十万年。晚年为求长生与勘破天道桎梏，受长生尊所授《长生经》，双双自斩帝身隐入禁区，与长生尊并称三大神尊。本命帝兵【天帝剑】。
- **人帝（人）**——双帝时代的另一根擎天柱，证道略早于天帝。其本命帝兵【天穹刀】借【太初鼎】祭炼而成，古意森然；与天帝止戈共治后合创《天人经》，保八域十万载太平。晚年同样自斩帝身、跌落"帝落"位格，潜入禁区化为人神尊。
- **古帝（妖）**——拓荒时代首尊妖帝，本体九日神鸟，兼负梼杌血脉。战力在同代不算最显，悟性却罕有人及，一生留下核心帝经《九势决》及《神文经》《平乱决》《铸体经》《古仙法》等诸多法门；本命帝兵【证仙】本身即是一部铸于器上的古经。晚年将传承与帝兵尽留人界，独身飞升仙界。
- **神凰大帝（妖）**——洪荒凤凰始祖。昔年曾被太初大帝亲手斩杀；凤凰不死本源在真死之后完成完整涅槃，于混沌中重育新胎，而非将旧躯简单封印。故其再世破壳时拥有全新生命年轮，合规踏入拓荒帝路（洪荒旧修为尽失，唯留部分本源与记忆）。她凭绝世天资极速重修，帝路之上几无苦战便横压群雄，创《不灭经》、炼十颗不灭丹、辟无尽深渊。面对三大神尊联手，她一人逼退三尊，复封印天神尊、重创人神尊，迫使三尊立下自封百万年之约。留不灭界与【不灭神羽】传说后飞升仙界，公认为最逼近无上帝的无双大帝第一人。
- **灭帝（人）**——幼年服不灭丹修成不灭体，旋遭灭族惨祸。此后在追杀中以血养剑，甫至问仙境便执【灭仙剑】血洗仇敌，甚至逆伐归一老祖，"灭"字威名震动星海。成帝后创核心帝经《灭仙决》与《三转法》，留传承后飞升仙界。
- **斗天大帝（妖）**——月狼族出身，少时遍参历代帝法、独闯禁区、数度生死涅槃，终将百家帝道熔为一炉，创《斗天九法》，九法合一而证得继太初之后的第二尊"无上帝"。其平生最深远的发现，是在与"化道"强者交锋中勘破了大帝之外的另一条通天路，将那未圆满之境定名为"半道"，倾囊授独子唯尽。晚年辟堕仙界，将九法分置九大禁区；虽有本命帝兵【九法战戟】，平生却只信己法、极少动兵，终飞升仙界。
- **剑帝（人）**——少时平定八域动乱，为人族护道柱石；成帝后创飞仙教，凭【飞仙剑】与《飞仙决》维系人族与星海秩序，门下"二十四剑星"中竟有三人踏入半道。后与唯尽道尊争锋数千年，于屡败中磨剑不辍，终借《不灭经》与不灭丹迈入无双大帝绝顶，与唯尽战平，旋即飞升仙界。
- **唯尽道尊（妖）**——斗天大帝独子，幼承父法，又曾随剑帝习剑。修至半道巅峰后，主动逼剑帝全力死战，以自断一臂为代价于生死一线间破境，成就**人界史册第一位道尊**；此后与剑帝连战数千载，留"十战九胜一平"之名。剑帝飞升后，恰逢天道尚未重释本源的漫长空窗，唯尽独坐人界约百万年，史称"唯尽镇世"（道尊在世并不阻塞帝路）。晚年留《唯尽法》与本命道兵【悟道剑】于人界，飞升仙界。
- **九玄大帝（妖）**——本体为洪荒遗种犼，凭【九玄扇】杀出帝路。成帝后立九玄殿、传《九玄法》，广收门徒，一脉长盛于妖族。晚年本人去向未详，【九玄扇】则传入万妖阁，化为妖族镇族重器。
- **铸天大帝（天）**——天族出身，生而亲近天地法则，少时游历八域、遍战诸族强者，一生以天族复兴为志。成帝后著《补天经》，本命帝兵【补天剑】亦化为天族象征。晚年无飞升明载，终隐没于宇宙深处。
- **古元大帝（人）**——起于微末人族部落，无显赫血统，亦无名门护持。乱世匮乏反磨出其惊人韧性；遍游诸域后融百家所学创《古元经》，铸【洪荒塔】镇守人族一方，被后世奉为"凡身亦可登帝"之楷模，终飞升仙界。

**太古时代**

- **祖龙大帝（龙）**——第一世生于洪荒末年，具先天混沌龙体，因血脉过烈遭龙族放逐。太初大帝崛起时，他曾以分身犯太初之威，三招即灭，本体亦受重创；遂仿凤凰真涅槃之理自创《归墟涅槃法》，主动毁去旧龙躯与九成九修为，将一点本源化为无意识龙卵。龙卵于混沌中沉浮数千万载，至太古前夕破壳诞出第二世祖龙——因系全新生命年轮，合规踏入太古帝路，重炼祖龙体而证道。成帝后撰核心帝经《祖龙经》（《归墟涅槃法》则作为最凶险的再生秘术单列流传），复历九万年征伐一统宇宙龙族，定青龙、应龙、烛龙、苍龙、玄冥龙五大支脉，留【祖龙玺】与诸法后飞升仙界。
- **古月大帝（妖）**——生命源头可溯至洪荒末年：吞月天狼与月桂神树共生时遗下一枚无完整意识的"残月胎"，漂流星空数千万载，至太古前夕方真正孕育出独立生命古月（故旧史所谓"生于洪荒末年"系指其本源胎体，非古月本人活过数千万年）。少时遭獬豸残脉追杀，寄身残月漂流三千载修成月蚀妖体；后借太初鼎碎片与太阳精魄补全阴阳道基而证帝。所创《古月经》分月蚀、葬月、太阴三卷，本命帝兵【葬月轮】。晚年与神冥道尊爆发长达八百年的"日月之战"，终力竭陨落，月光本源与【葬月轮】遂落入冥族之手。
- **神冥道尊（冥）**——葬神墓地孕育出的先天冥灵，冥族开山鼻祖。在与古月大帝死磕的八百年间，凭《往生咒》、替死傀儡等诡谲冥术屡屡自必死之局脱壳，终在生死消磨中破境道尊，著核心传承《幽冥往生经》（《往生咒》即其麾下第一秘术）。决战之日借太初古矿时间裂隙避开古月大帝绝杀"月殒"，反手格杀古月。其本命道兵【幽冥镜】封存月光本源，永镇冥族。
- **古灵大帝（灵）**——诞于九星秘境域灵能漩涡，生具七十二道先天灵纹。成帝后曾独力弹压魔骨血海大暴动，拘十万凶灵铸就本命帝兵【灵枢】；与应龙道尊三百年死战中故意留一线生机，成全对方破入道尊。著《古灵经》；飞升前夕分化己身灵体为九大灵脉，化作灵族绵延至今的命脉。
- **应龙道尊（龙）**——应龙支脉出身，早年为祖龙大帝关门弟子，尽得祖龙三大传承，一路修至绝巅。为求破境，亲手剜下逆鳞死战古灵大帝，龙躯被【灵枢】打碎后借青龙精血与九天雷罚涅槃，修成万劫龙体而登临道尊。著《应龙法》，铸本命道兵【劫道刃】；晚年人与道兵皆不知所踪。
- **释天大帝（人）**——平生九次自废修为、九度从头重修，终铸就九转金身，著《释天经》立下后世佛门道统根基。曾独闯魔骨血海，以【释天剑】将半道魔祖钉死于血海；亦曾随手点化后来证帝的扫地僧古佛。飞升前夕斩出己身恶尸"灭世尊"，复以善念将其镇于西龙洲古佛宗底，开佛门善恶二尸之先河。
- **古仙大帝（天）**——生具天族九窍仙心，少时便威压族内。成帝后重订天族修行法度，著《古仙法典》，令天族彻底挣脱对神族的依附；复亲斩神族伪帝，剖其神格铸成【戮神矛】。晚年自化三成修为作【葬仙链】，永世锁镇无道死地核心，化为天族最深厚的镇族底蕴。
- **化灵大帝（灵）**——灵族大帝，平生所求唯"化"与"融"二字。逢九星秘境域中央灵能漩涡崩塌，他毅然自碎本源灵核重塑一方天地，崩散的灵核残片凝为本命帝兵【万灵鼎】；后著《化灵经》试图打通各族功法藩篱，又将东华洲兽谷炼作"万妖灵冢"留作灵族试炼场，终飞升仙界。
- **古魔大帝（魔）**——诞于魔骨血海，靠吞噬累世古魔残骸修成不灭魔躯，一生与雷劫杀伐相伴。所著《古魔经》专取天劫雷火反淬魔躯，本命帝兵【万魔塔】更曾生囚十二位各族巨擘以血气供养魔土。成帝后与神冥道尊暗结血契，定下魔、冥两族万古同盟；晚年去向成谜。
- **祖鹏大帝（妖）**——起于北海之极，吞上古鲲兽而兼得海、空两极大道，抽自身神骨炼就帝兵【天鹏骨翼】。所著《九霄鹏程诀》几将虚空本身化为坦途，极速冠绝太古；成帝后平定九部古妖族叛乱，将叛军精锐尽数炼为鹏影卫，并于葬神墓地刻下鹏族图腾，为后世妖族出入禁区留下一线活路。
- **夜帝（人）**——未循常例入帝路搏杀，而是趁太初古矿大暴动之际，凭《暗蚀经》遮蔽周天天机，暗中横夺天道本源一步登帝。成帝后斩九光神子，取其神骨铸成帝兵【夜狩】，并与李族、古夜族等人族巨擘结盟，留多脉暗系秘术。晚年与无天道尊死战至平手，立契罢兵，旋即飞升仙界。
- **无天道尊（神）**——神族弃子，一生皆在反抗先天血脉与天道烙印。趁夜帝征伐四方之际，他强引神罚天劫硬接【夜狩】三箭而不死，反手夺舍九光神子残躯，生生剥去神族血脉中的天道印记，于大战中破境道尊。所创《无天逆命经》专司逆转外加之血脉禁制、神力束缚与命数锁定。与夜帝战平后，双方以《暗蚀经》交换神族默许"夜影阁"存世之契；晚年携本命道兵【逆命梭】飞升仙界。
- **古藏大帝（妖）**——妖族罕见的文明立法者。早年吞炼九大禁区凶兽精魄，铸就本命帝兵【炼神妖壶】；登帝后却敛去杀伐，著《古藏妖典》、创制统一妖文，令散落八域的万千妖族首次拥有共通典籍。其门人后演化为中洲万妖宗中坚，奠定妖族在帝落域的万年基业；古藏本人晚年失踪。
- **神龙大帝（龙）**——玄冥龙支脉异种，逆炼青龙精血后竟兼显应龙金翼与烛龙瞳纹，修成罕见的四脉合一龙皇之躯。著跨脉帝经《四脉龙皇经》（以玄冥为骨、青龙为续、应龙为锋、烛龙为神），取万年蛟珠铸寒气滔天的本命帝兵【玄冥镇界戟】。值祖龙飞升后龙族内乱，他以铁腕弹压苍龙、烛龙两脉叛乱，重划五脉疆界，今日古域龙族版图多定型于此。
- **道天大帝（人）**——生具道源灵体，精擅观星象、推演天道运转。著《道天经》，取天道碎片铸【天衍盘】。其治世极重法度与格局：弹压妖族动乱、重划帝落域版图，今日"五会"中人族三会（李族、神武族、古夜族/星族前身）的早期根基皆成于其手。飞升前将部分天道体悟封入中洲天机阁，携【天衍盘】飞升仙界。
- **天姬道尊（妖）**——本体九尾天狐，靠吞炼古妖血脉修至绝巅。以幻道、血脉与遮蔽天机立身，曾布"九尾迷天阵"搅乱周天天机，引道天大帝亲临问罪；二者由生死斗法转为坐而论道三日，天姬遂于论道间勘破关隘，晋升道尊，著《九尾迷天经》。此后一帝一尊共铸道兵【天机双生佩】、同立天机碑，定下人妖两族共掌大势之局。天姬飞升后，双生佩化作双子星永留人界。
- **长河大帝（妖）**——本体为洪荒异种时河鲲，天生亲近时间法则。本命帝兵【时河钟】可强行回溯极短光阴，然每一次催动皆须燃烧执掌者寿元；所著《长河经》则将缥缈时间之道化为妖族可修的法门。长河飞升后，围绕时河钟仿品与"时墟"形成的道统，至今仍攥在东华洲极天妖族手中。
- **古佛大帝（人）**——原系释天大帝随手点化的一名扫地老僧，亲历恶尸"灭世尊"祸乱后大彻大悟。著《古佛经》慈悲、明王、轮回三卷，收释天剑残片与灭世尊残躯熔炼出本命帝兵【因果轮】。成帝后横扫鬼族，拘七十二鬼王封入镇魔塔，彻底坐实佛修在八域的顶层席位；飞升前亦效先师斩出善尸"渡世尊"留镇古佛宗。
- **时空大帝（鬼）**——诞于葬神墓地的先天时空鬼灵，自幼可捉摸零散时间碎片。潜伏楚域九幽仙宫期间吞噬上古鬼皇，彻底觉醒时空本源，撬青铜古棺核心铸就本命帝兵【时空刃】。著鬼族根本帝经《时空经》；晚年行迹失载，不知所踪。

**天武时代**

- **武帝（妖）**——太古魔猿与混沌石灵共生之躯，早年因体魄凶威过盛遭妖族排斥，遂走出一条"以战养战"的纯粹武道。成帝后著《武帝战典》，于中洲立万妖武殿与生死武斗场，聚万兵熔炉铸就【荒武战甲】。麾下九大武尊、六支新血族群及绵延后世的"武劫之制"，令整个天武时代皆烙上其拳印。
- **天妖大帝（妖）**——本源传系洪荒第一缕先天妖气；那缕妖气散入万妖血脉流转数千万载，直至天武时代方重聚出独立自我（非同一意识自洪荒苟活至今）。天妖无形无相，可拟化天下万妖；吞炼诸多洪荒凶兽后修成万妖源体，著《天妖万化经》，执【万妖幡】召引古妖亡灵，掀动席卷帝落域的"万妖劫"。飞升之际，他亲手引爆【万妖幡】，将漫天妖灵尽数打入天下妖族血脉，后世妖族著名的"狂化"天赋即源于此。
- **天鹏大帝（妖）**——吞天云鹏与雷泽神鹰的混血遗腹，因血统驳杂遭鹏族放逐。独栖飞仙域九天罡风层万载，引九天神雷熬炼出九劫雷鹏体而证道。所著《九劫天鹏经》融雷法、极速与破界于一炉；本命帝兵【裂宇爪】曾一击撕裂楚域万里疆土，留下一道经年不合的"天痕"。
- **赤凤道尊（妖）**——血焰凤凰与冥火幽凰的变异后裔，幼年因体内生灭二火失控被流放魔骨血海。于血海中吞炼凶灵、修成生死凤炎，著《生死凤炎经》，取自身褪羽铸本命道兵【焚界铃】。在与天鹏大帝的终局死战中，赤凤燃尽周身凤炎，拖天鹏同坠"生死火冢"，于死生一瞬强行破境道尊——是役余波甚至将古域九龙谷的半边空间彻底扭曲。
- **天蛟大帝（妖）**——北烟洲北海蛟族的混血异种，兼负玄冥血蛟与洪荒雷鳗血统。早年被逐入魔骨血海，靠啃噬古魔残骸炼体；帝路争锋中强夺天道本源、硬抗九重混沌劫证道。著《化龙经》，执寒雷滔天的【镇海雷狱戟】。晚年妄图吞噬不灭凤炎、孤身强闯化心域无尽深渊，终遭深渊底部的洪荒妖灵反噬，帝躯崩裂，临死自爆帝兵，狂暴雷狱残威至今仍在深渊底部咆哮。
- **武凤大帝（妖）**——凤凰与魔猿血脉交融所诞，兼备焚天烈焰与蛮横肉身。成帝后一度整合妖族各脉，立焚天宗，传《焚天经》，本命帝兵【荒焰战甲】威震天武。他未如前代诸帝般急于求索飞升，而是长留人界经营妖族根基。
- **天儒大帝（人）**——人族儒道开山之祖。早年遍读百家典籍、徒步丈量八域，于人族式微之际重理教化与修行之脉，终创《天儒经》，化"仁、义、礼、智、信"为五条通天修行路。成帝后执【天儒笔】传道立教，令儒门自此跻身八域显学；晚年飞升仙界。
- **丈史大帝（人）**——出身人族古老修史世家，自幼对岁月长河与因果流转有异乎寻常的敏锐。所创《丈史经》直指历史、光阴与因果大道，本命帝兵【史册】即其道果载体。在位期间屡屡于时代大势拐点落子，系后世最难单纯以攻伐战力估量的一尊大帝；晚年飞升仙界。
- **龙帝（龙）**——后世龙族最具传奇色彩的帝者，生而近乎无敌，不假繁复法则，纯以无匹龙躯、个人"龙道"与天地共鸣横压当世（其《龙道真经》后人虽可修习，却无人能复刻其独一无二的个人龙道）。在位时曾正面击溃暗中出世的三大神尊！本命帝兵【龙皇印】与龙族传承重宝【龙魂珠】虽常随其征战，其一身战力却从不系于外器。晚年飞升仙界，古域龙族亦借其余威再登鼎盛。
- **浮龙大帝（龙）**——毕生求索不灭龙躯与龙族绝对威权。修《浮龙无极诀》登帝，持【浮龙紫电矛】驾雷破空，又引周天星辰灵气修成"浮光"领域。在位期间倾尽全力弹压龙族内外叛乱，重整五脉纲纪。
- **振武道尊（妖）**——承接妖族上古武道而起，修《振天无极诀》，出手可化天地元气为万千战影；本命道兵【武尊铁拳】专司以力破法。较之开宗立派，其最大功绩在于重新梳理妖族支离破碎的古武传承，并于融汇百家中踏足道尊；晚年人与铁拳皆不知所踪。
- **截天大帝（天）**——天族鹰派巨擘，以一"截"字贯通大道，创《天道断裂术》，本命帝兵【断天弓】尤擅破隐、破界与超远距狙杀。在位时以铁腕压服四方，令天族疆域再度横跨大片星海。
- **斩天大帝（天）**——天族杀伐最盛的一尊大帝，以《斩天破界诀》证道，本命帝兵【破天剑】专破大阵、斩裂界壁。在位期间征战不休，以有进无退的剑锋撑起天族霸权。
- **始尊大帝（妖）**——身负上古妖族源血，创《始妖传世诀》统合妖气与万灵之力，另辟奇术【灵魄吞噬术】，执擅束魂夺力的本命帝兵【妖魂长鞭】。在位时致力于将松散妖族部落捏合为守序整体。
- **斗战大帝（妖）**——生具拔山巨力，自妖族古武《天兽之力》中杀出一条纯粹至极的斗战大道；证帝后将其升华为核心帝经《斗战天经》（原《天兽之力》化作其中炼体与爆发筑基篇），执【战神巨锤】遍挑战海强者，未尝厌战。
- **普华大帝（冥）**——冥族大帝，专修生死、魂魄与冥河大道，著《冥河洗魂术》，持可拘拿万魂的【冥轮引魂杖】。成帝后一改冥族世代潜伏暗处的旧习，悍然率族出世开疆拓土，造就冥族史册罕见的鼎盛皇朝。
- **白朴大帝（妖）**——洪荒十大神兽"白泽"的隔世再生。昔年太初大帝横扫十族时，白泽凭趋吉避凶的天机本能提前窥见死局，未与太初硬碰，而是当场自绝完整生命，舍弃洪荒肉身、神魂与九成九本源，仅遗下一枚无意识的"白云种"（故洪荒白泽在天道层面确已身死，非自封苟活）。千万载后，白云种于天武时代重育出全新生命"白朴"，年轮自新生起算，合规入帝路。白朴在修行中渐次苏醒白泽记忆碎片与天机本能，创《白云冥神诀》，执【天火紫焰扇】证道。平生不好蛮战，专擅谋势布局，于西龙洲立白朴寺一脉；晚年留【天火紫焰扇】于人界，飞升仙界。
- **五色大帝（人）**——天武末期人族大帝，出身西龙洲一处五行小国。少时因体内五行杂驳相冲而久居人后，终自"相克亦可相生"中勘破轮转妙谛；帝路之上最擅拆解敌手攻伐、化为己用，执【五色轮】证道。著《五行轮转经》，于西龙洲立五色神朝，将苛求单一灵根的旧五行法改写为五气互转之学，令无数资质平庸者得窥大道门径。飞升前将【五色轮】留镇五色神朝。
- **避神道尊（人）**——五色大帝早年结伴同游的散修知交，后因道途迥异分道扬镳。避神认定修士越仰赖天机、血统与世俗名位，便越易沦为高阶存在的靶子，遂终生参研"自天地感知中抹去痕迹"的大道。他未入帝路，反在五色大帝登位后，恳请挚友以无上帝威、周天天机与五行大阵彻底封锁整片星域，自己则于绝锁之中尝试不破阵而脱锁；苦熬九日，终在帝威眼皮底下凭空消失一瞬，由此破入道尊！著《避神无踪经》，成道兵【避神衣】（可遮蔽气息、因果与气机锁定，然仍不脱天道本身）。五色大帝飞升后，避神复在人界驻留数十万载，终无声隐没，人与【避神衣】皆不知所踪。

**开盛时代**

- **神帝（神）**——天武末年，神族因累世闭锁与嫡庶血统内耗渐趋衰颓。神帝出身神域旁支，早年反常年流落外域，于帝路中博采诸脉神力，终执【神辉印】证道。著《神辉万象经》，可统合异种神力而不伤其本源；同时废除族内极端血统禁令，立准许旁系与流落族人归宗的"神庭议约"，令神族重返八域棋局（【神辉印】亦化作神族大军战阵的增幅中枢）。晚年携印飞升仙界。
- **星空大帝（人）**——出身帝落域星族前身的观星世家。青年时耗数万载光阴徒步丈量八域星路，将散落孤立的上古传送阵、虫洞与安全航道编纂为统一星图；帝路争锋中凭星辰坐标超远距转战夺得本源，以【周天星图】证道。著《周天星辰经》，主持重修八域跨域星门网，并倡立各顶尖道统的常设跨域议事机制（即后世归一联盟的制度雏形）；星族亦凭把持星图、星门与航道一跃跻身"五会"之列。飞升前将【周天星图】留镇星族。
- **储圣大帝（人）**——起于灵气枯竭的偏远小界，早年不擅爆发，唯精于将灵力、术法、阵势乃至敌手攻伐层层封存，终推演出"储势大道"。证道后著《储圣万法经》，铸本命帝兵【储圣册】。他深感历代传承皆被血脉世家与大宗垄断，遂于中洲创"帝院"初制，许八域寒门天骄凭考核而非出身习得高阶帝法；又于各域建多座跨纪元资源库以备禁区暴动与大灾赈济。晚年坐化前散尽九成私藏反哺天地，唯【储圣册】永封于帝院最深处。
- **天秘大帝（天）**——天族出身，自幼能窥见天机运转留下的"缺口"，亦由此深悉过度推演对天地与推演者自身的酷烈反噬。他以封存、梳理与斩断信息因果入道，执【天秘牒】证帝，著《天秘无相经》。在位时未立世俗皇朝，而是联手天机阁等道统立下高阶推演三禁：禁大规模窥探凡俗未来、禁以天机术长年操控帝路争锋者、禁公开宣扬禁区核心坐标。此三禁虽非铁板天条，却自此化为八域天机师默守的底线。晚年携牒飞升仙界。
- **玄武大帝（妖）**——本体为玄甲古龟（非洪荒十大神兽）。楚域昔年因天鹏大帝【裂宇爪】留下的"天痕"及累世大战，遍布不断蔓延的空间裂口；玄武早年便以修补裂界为业，融地脉、空间与守御于一炉，于帝路中凭"守至万夫莫开"硬生生熬得本源归身。著《玄武镇界经》，铸【玄武碑】，耗数万载光阴镇平楚域最大的七处空间断层，令无数荒废星路重开。飞升前将【玄武碑】永镇于楚域第一大裂口核心。
- **青龙大帝（龙）**——出自青龙主脉旁枝，早年并非族中最受瞩目的储君。其道不求极致毁灭，唯重"木行生生不息"，凭恐怖的龙躯再生力与连绵攻势于帝路末期硬熬过数轮围杀而证道。著《青龙不息经》，执兼具生机与破阵伟力的【青木龙槊】。在位时消弭五大龙脉积攒百万年的领地与血统宿怨，订立五脉共护古域祖脉之盟，并将部分亚龙、蛟族正式纳入外围龙裔谱系。飞升前将【青木龙槊】留镇古域，令龙族一门多帝兵的底蕴再添一筹。
- **神赤大帝（妖）**——出身天朝域微末的赤羽妖族。早年亲历本族沦为大势力征伐炮灰的惨剧，深恨无休止的部族损耗；遂以血气与战意入道，化"死战"为"凝万众为一心"。著《神赤战经》，铸可放大同源血脉与军阵共鸣的【神赤战旗】。在位时强行按停天朝域绵延数万年的多族混战，立下大教征召附庸族群的法度底线，并力推妖族诸脉入席归一联盟。晚年于魔骨血海一次大暴动中受创，数万载后伤发坐化；【神赤战旗】由后裔护送离天朝域，今下落不明。
- **地藏大帝（人）**——开盛时代最后一位载入公开正史的大帝。少时常年在帝落域边缘星辰修补崩塌地脉，一生道心唯"大地载物而不争"。帝路末期借八域地脉与星辰引力构筑不破阵地，以【地藏图】证道，著《地藏镇世经》。平生最大功绩，是独力按住葬神墓地一场几欲吞没帝星的大暴动，并将墓地外溢的滔天死气导入数百颗荒芜死星，化为拱卫帝落域的缓冲带。晚年地藏大帝孤身步入葬神墓地极深处，自此再未现身；数十万载后，其留存人界的帝威与天道印记彻底消散——这证明其帝位在天道层面确已终结，至于究竟是暗中飞升、坐化墓底，抑或在禁区深处遭遇莫名之变，连同【地藏图】的去向，至今无人得知。

**大帝更替与双帝、帝尊并世通考**：
大帝正常寿数约二百五十万年。常例之下，当世若有一帝在位，天道绝不重释本源；唯旧帝位终结、再历数百万载空窗，天道方释出一缕本源开启万年帝路。史册唯一的"双帝时代"（天帝、人帝共治），系天道在特殊历史节点主动降下第二缕本源的罕见破例，非后世修士所能强求复刻。至于同一时代出现"一帝一道尊"（如剑帝与唯尽、古月与神冥、道天与天姬、五色与避神），则因道尊破境根本无须天道本源——多系一人先夺本源证帝，另一同代天骄与当世大帝死战不退、临阵破开己道而晋升道尊，二者本不冲突。

**帝尊高下之辨**：
公开正史中，唯**太初大帝、斗天大帝**二尊确凿登临"无上帝"；**神凰大帝**巅峰时居"无双大帝"绝顶，距无上帝仅差一线（今已飞升仙界，非当世在位）；**天帝、人帝**全盛时亦属无双大帝，自斩帝身后则跌落"帝落"位格（昔年三大神尊围攻巅峰神凰，全赖长生尊祭出太初大帝遗留的【太初鼎】，借无上帝兵位格方压住【不灭神羽】）；**剑帝**早年属普通大帝，与唯尽道尊磨剑数千载后亦迈入无双大帝；余如**古元大帝、灭帝**等，则属普通大帝之列。

### 人物传

**长生尊**：

仙界孤本《长生经》在人界的唯一传人，亦是正史六十一尊谱系之外唯一的"隐帝"。

洪荒年间，长生尊机缘巧合拾得自仙界坠落的《长生经》。此经专靠窃取、吞噬归一境以上强者的寿元与生命本源延命（问仙以下生灵几无效果）。神化时代，他与尚未成帝的逆天大帝交锋数十场，终败于对方在生死间悟出的《逆天决》；待逆天大帝与三清时代遗留的天尊恶念决战同归于尽，长生尊竟趁隙以恶念残存的最后一丝生机换得一缕天道本源，暗中证道大帝，并在成帝刹那借恶念之力**彻底斩断自身与天道的持续感应**。

这一手造就了人界古今唯一的"隐帝漏洞"：**长生尊已完成货真价实的大帝位格蜕变，坐拥大帝寿元、帝级本质及一件必然存在却从未曝光的本命帝兵；然天道自其证帝后便无法感知其存在，后世大帝更替亦从不将其视作"当世仍有大帝在位"。**故他既不入公开五十三帝正谱，亦从未阻塞后世帝路开启。

拓荒时代，长生尊将《长生经》分授晚年求索长生的天帝与人帝。双帝遂主动自斩帝身、跌落为"帝落"层次并隐入禁区，与长生尊结为"三大神尊"（天神尊、人神尊、长生神尊）。神凰大帝当世之变中，三大神尊联手出击，且由长生尊祭出暗中自太初古矿取走的【太初鼎】，方勉强逼退巅峰神凰；战后三尊依约自封百万年。

岁月推移之下，寻常归一境区区四十万载的寿元与生命本质已难填长生尊之欲。自太古时代起，他渐将猎食目光转向当世大帝——每吞噬一尊大帝的残余寿元与部分本源，所得皆是帝级生命与大道积淀。数千万载至今，已有数位大帝遭其暗算吞噬，其一身战力亦无限逼近无上帝，唯终差最后一线未能跨过。因天道无从追踪，八域明面上的顶尖道统至今不知"长生尊仍活在世间"的完整真相；他与天神尊、人神尊的暗面盟约亦延续至今，只是三尊各怀心思，唯靠长生之欲与规避天道清算的共同利害维系。

## 当前世界状态

**明面格局**：人界正处开盛时代后期。上一任公开大帝地藏大帝步入葬神墓地深处后，其帝威与天道印记已自人界彻底消散，故**当世明面状态为"无帝"**；然天道尚未降下新一缕本源，八域正处于"旧帝已去、帝路未启"的漫长空窗。按史册常例，两代帝位之间动辄相隔数百万年，顶尖道统唯有凭天机推演知晓"下一世帝路日近"，却无人能断定确切年岁。

当世最庞大的公共协调体系仍系延续数百万载的归一联盟，五会把持长老院最高话语权；全宇宙约二百三十位归一强者中，盟内占约一百六十席。帝落域依旧稳居八域之首，帝星五洲则是全宇宙顶尖道统最稠密的单一生命古星（妖族在帝落域的绵延根基奠定于太古古藏大帝，五会中人族三会的早期雏形则定型于道天大帝之手）。

**暗面潜流**：长生尊依旧在世。因其早年已斩断天道感应，既不阻塞新帝路酝酿，亦不被归一联盟与天机阁的常规推演所察；自斩帝身的天帝、人帝亦仍以"帝落"位格蛰伏于禁区暗处。三大神尊至今仍是悬在八域头顶最大的未知变数。
