# 使用原则

这是按需检索的创作辅助，不是事实源、章节配额、应用卡或开稿门槛。大纲决定目标，人物决定行动，连续性决定已发生事实，固定文风决定写法；本文件只在冲突已确定后提供可选因果结构。没有合适机制时可以不采用。

# 修炼与道路机制

- **失败留下可验证成果**：适用于已付出真实代价的旧失败；将有限经验、线索或关系债转为局部选择权。收益：少走关键弯路。代价：今世身体与环境仍须重新验证；不得免费补偿。
- **路线校正**：常规路线与当前身体/处境不适配时，先说明其好处和缺口，再尝试有失败成本的替代法。收益：形成不可替代根基。代价：过程高风险且不可复制。
- **先补底盘，再进终局**：目标诱人但能力有缺口时，主动放弃短期机会进行训练、复盘或重组。收益：下一次能完成此前做不到的动作。代价：真实错过机会并承受误解。
- **死路改写，先付账单**：公认绝路先以失败前例、过程与不可逆风险压实，再完成有限突破。收益：修为或方法突破。代价：伤损、救治债或选择收窄。

# 战斗与反制机制

- **低位试探的有限反制**：对方合理试探越界后，以短而可解释的动作立住底线。收益：入口或谈判位置。代价：留下识别痕迹。
- **招式互斥条件**：先展示敌方攻防不能同时完满，主角承压观察后择机反击。收益：战法验证或战果。代价：伤势、消耗或边界暴露。
- **对手升级**：每次失败后，对手应改变解释、准备、结盟或规则策略。提醒：不能反复轻敌挨打。

# 资源、资格与规则机制

- **稀缺资格归属争议**：资格、试炼、典籍或师承只能给有限人。收益：冲突直指修炼环境。代价：各方都要有真实损失，不能只靠嫉妒。
- **公共规则内反转**：在公开限制、记录与见证下，以准备、技巧和判断反制压制。收益：合法资格、资源或记录。代价：名声扩散，既得者调查。
- **打破标杆，换来选择压力**：以可验证指标越过旧纪录。收益：新场域资格或资源。代价：失去隐身空间并被要求站队。
- **残缺奖励的延迟显值**：先给出残物/线索异常证据，后在条件满足时部分显效。收益：破局钥匙。代价：使用门槛、保管风险与识货者关注。
- **敌方准备反成窗口**：读出资源控制链，在对方无法放弃的窗口改变归属。收益：资源与敌方情报。代价：消化风险和升级追杀。

# 认知差与名声机制

- **信息分层**：读者、主角、亲近者、敌人各知不同部分；误判必须有信息依据。收益：认知差成立。代价：隐瞒会损害信任或引来审查。
- **高调窗口**：只在能换长期资格、锁定公开条件或进入高阶场域时亮牌。收益：位置改变。代价：名声、敌意与责任同步到来。
- **名声成为保护，而非代打**：用可信战绩公开绑定关系与底线。收益：亲近者获得自主成长空间。代价：主角树敌，亲近者不能停止成长。

# 人物关系与家庭余波

- **家庭结算战后代价**：伤势、隐瞒、资源与责任须在亲近关系中结算。收益：信任或交托变化。代价：追问、分歧或边界。
- **公开与私下评价错位**：外界评价战绩，亲近者看见代价。收益：人物关系立体。代价：主角无法只靠名声解决私人问题。
- **技术分歧产生合作或竞争**：双方对同一修炼问题有不同可验证答案。收益：信息、方法或暂时合作。代价：目标冲突持续存在。
- **任务外的生活选择**：训练、修补、交易、照料或承诺必须改变技能、关系、资源或下一次选择。提醒：不为凑日常停摆。

# 探索、合作与地图变化

- **条件合作**：有明确胜负后，以有限承诺换路线、侦察或环境能力。收益：短期盟友。代价：对方保留离开与翻脸筹码。
- **地图改变逻辑**：新场域至少改变一种资源、关系或胜负条件。提醒：不能只换地名和数值。

# 失败、代价与后续回响

- **旧因果回响**：早期的人、物、名誉或制度痕迹在新阶段改变阵营、资源或目标。收益：世界连续。代价：旧债与敌意一并回来。
- **污名夺回定义权（局部）**：只有真相能改变当前修炼选择、阵营或敌人时，才以证据和行动重估旧评价。提醒：不得压过修炼、资源和战斗主线。
- **主动撤退保存火种**：硬拼会覆灭时，承担骂名让人和资源分流。收益：未来重组基础。代价：失地、名声受损和关系断裂。

# 叙事执行技法

- **三段认知翻转**：冲突前建立合理预期；冲突中只在变化处给旁观；冲突后让不同人得出不同结论，并让一条结论进入后续。
- **账本式收益结算**：写清得到了什么、失去什么、谁因此改变行动；不只报境界和掌声。
- **余波钩子**：至少让伤势、资源、评价、流言、关系或敌方复盘中的一项延续到下一章。
- **关系中的具体认可**：父母、师长、同辈与竞争者以不同动作、资源或托付表达重估，不使用同质赞词。
