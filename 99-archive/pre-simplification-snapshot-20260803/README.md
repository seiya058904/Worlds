# 小说创作工作文件夹

这是供 Codex 长期独立创作小说的 Markdown 工作区，不是软件项目。用户提供世界观、人物、偏好、禁区与反馈；Codex 负责整理资料、完成全书设计、撰写正文并维护一致性。

正文前必须完成并获批准：根基设定、主题、人物弧、完整结局、故事路线、节点、伏笔、信息揭示、章节大纲、文风规范与开稿审计。正式设定以用户明确资料和已批准设计为准；`scratch/` 想法与校准样稿均不是正式设定。

## 目录

- `00-project/`：状态、原始输入、硬性限制、参考拆解。
- `01-foundation/`：世界、人物、关系与术语根基。
- `02-story-plan/`：结局、结构、节点、伏笔和章节大纲。
- `03-writing-standard/`：文风、对话格式、节奏与校准。
- `04-manuscript/`：仅存放正式章节。
- `05-continuity/`：正文后的状态、时间线、知识边界与 Canon。
- `06-review/`：开稿、章节与全局审查。
- `scratch/`：候选或已放弃想法，不是正式设定。

## 使用方式

提供原始资料后，先要求 Codex 记录或整理；再依次完成整体设计、章节规划、文风校准、开稿审计。只有你明确批准整体方案并允许开稿后，Codex 才会创建章节。可以要求指定章节写作、局部修改，或先进行全局一致性审查。

## 示例提示词

```text
读取我接下来提供的资料，将原始内容整理进 raw-input.md。暂时不要补全故事，不要写正文。
```

```text
根据 raw-input.md 整理世界观、背景历史、主要人物和硬性限制。允许补全必要细节，但必须区分用户事实和 Codex 设计。
```

```text
在现有设定基础上，独立完成主题、人物弧、完整结局和全书主要故事路线。不要写正文。
```

```text
根据已经确定的完整故事路线，完成全部主要情节节点、伏笔计划、信息揭示顺序和章节大纲。
```

```text
根据参考作品和我的文风要求完成文风规则，并生成非正文校准样稿。不要创建第一章。
```

```text
执行完整开稿前审计。未达到全部条件时，不得开始正文。
```

```text
我批准当前完整故事设计和文风规范，允许将状态改为 APPROVED_TO_DRAFT。
```

```text
按照已经批准的第一章大纲写第一章。完成后自行审查并同步所有连续性文件。
```

```text
只润色第一章指定段落，不改变事件、信息、人物动机、对话含义和文风方向。
```

```text
审查目前全部正文的人物知识边界、时间线、世界规则、伏笔和文风一致性。先报告问题，不要直接重写。
```
