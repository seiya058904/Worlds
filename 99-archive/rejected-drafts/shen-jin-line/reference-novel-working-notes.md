# 参考小说可用技法

> 已读取 `D:\下载\玄幻：逆命万世，我打爆仙帝.txt`、`完美世界.txt`、`遮天（精校版）.txt` 及 `世界观.txt`；原文为 GBK 编码。只记录可迁移技法，不复制其表达、人物、专名或剧情组合。

- 连载开场先抛出可即时理解的矛盾或异常，再快速兑现一层结果；人物背景、世界规则和长期目标跟随结果补入。
- 一段人生先给“此身是谁、眼前缺什么、可抓住什么”，再让修炼、亲缘、同伴与竞争围绕同一目标互相挤压。
- 时间跳跃必须跨过重复劳动，只保留修炼结果、关系变化与新代价；新一世用一个身体限制和一段家庭关系迅速落地。
- 前世死亡不必反复悲情回放，应进入当世判断：不再轻信、懂得留退路、珍惜某种关系或避开一条旧路。
- 突破、大比、复仇、机缘与势力变化要服从阶段目标；战斗结束后立即兑现资源、身份或关系变化。
- 轻松感来自人物的务实反应和小摩擦，不用现代热梗破坏世界气氛。
- 大场景用少量强物象建立压迫和尺度，随后落回人物可感知的危机；战斗以位置、限制、反制和后果维持可读性。
- 章末钩子优先给具体的新问题：资格被夺、线索现身、代价暴露、敌人先一步行动；地图随资源和任务扩大。
- 旧人旧势力的后世影响以遗物、后代、规矩或历史后果出现，不让旧人无代价复活。

明确排除：系统加点、逆命空间、延迟觉醒前世记忆、把新身体写成原主身份、过度现代网络梗，以及直接复刻参考小说。
