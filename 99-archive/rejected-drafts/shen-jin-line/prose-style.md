# 文风 v0.1：参考分析抽取

第三人称限知，以主角为观察中心；开篇先给危机、目标或异常，再让世界观从后果中露出。修炼和行动优先，语言通俗流畅、节奏明快；人物由选择、利益与行动显出性格。

- 段落以 2—5 句为常态；战斗拆成“动作—判断—反制—结果”，关键撞击可独句。
- 对话短而有目的，连续四轮内必须落回动作、环境或新信息；不用“淡淡道”“全场死寂”等套话。
- 内心活动只服务于当前选择。前世记忆以一个能改变当下决策的经验、遗憾或手感出现，不作履历陈列，更不能代替此身修为。
- 修炼先写身体感受、资源限制和可见进步，再解释原理；越级必须有环境、准备或代价。
- 群众反应只承担信息、立场或压力，不为主角喝彩凑数。
- 功法、法宝与地名命名简洁、有物性和层级感，不堆生僻字，不沿用参考作品专名。
- 时间跳跃须交代经过时间、做了什么、状态如何变化；人生转换明确是正常新生，绝不写成夺舍苏醒。
- 每章以“欲望—阻碍—主动出手—明确回报—更大压力”完成一次追读闭环；章首从压力、动作、异常或有效对话切入，章末留下新代价、发现或主动目标，不能硬断动作。
- 禁止：设定讲义式开场、过度现代网络梗、全知剧透、复制参考作品的句子/人物/桥段组合、以“原主”称呼今生身体。

本版待前三章用户反馈后修订为 v0.2；尚非最终固定文风。
