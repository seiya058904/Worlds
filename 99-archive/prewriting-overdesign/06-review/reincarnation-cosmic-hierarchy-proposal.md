# 轮回小说宇宙层级与舞台展开提案

> 状态：待用户审核；仅做顶层归类，不修改人物、人生、八卷或240章。资料优先依据用户原始《世界观》中的八域、帝星五洲、九族、九禁区、归一联盟、五会与境界数据。

## 1. 宇宙空间树

```text
宇宙
├─ 八域（最高常规空间层级）
│  └─ 星海区（八域内的大星团/航道共同体）
│     └─ 星系
│        └─ 星球
│           └─ 星球内部区域（洲、陆、王朝、城池、宗门山门等）
├─ 混沌边界（宇宙外缘）
├─ 帝路（特殊试炼空间）
└─ 仙界（远古/终局背景，不作常规行政层级）
```

标准名称推荐为 **星海区**：它承载“大星团＋主航道”的叙事功能；“域”只指八域，“星系”只指星海区下的恒星系统。停止把星域、星区、星海域、大域混用于这一层。

## 2. 术语统一

|术语|正式定义|处理|

|古域|八域之一的专名，仅指龙族根基所在八域|禁止作“古老区域”泛称|

## 4. 势力等级

|级别|控制范围/常见坐镇|资源与交通|归一联盟关系|
|---|---|---|---|
|地方级|城镇、州郡、星球局部；练气至化神|地方矿脉、商路、短程阵|受所在星球秩序约束|
|星球级|一颗星或一洲；问鼎/问道传承|整星资源、星港或跨星节点|报备、纳约或受执法分殿监管|
|星系级|多颗星、完整星系；问仙强者与舰队|星舟军、星系传送、贸易网络|与联盟签航道/战争协定|
|星海级|多个星系；至少归一底蕴或接近归一的集体实力|跨星系军团、古阵、核心古星|联盟合作方，可参与跨域事务|
|域级|影响八域之一；归一强者、帝兵或大帝传承|域内资源、帝路资格、跨域通道|联盟核心席位或强合作方|
|宇宙级|跨八域；多位归一、帝兵体系与长期秩序能力|宇宙交通、跨域军团、重大裁决|归一联盟为最强公开组织；整体龙族、帝路体系为特殊同级背景力量|

原始数据校准：一位归一坐镇即可称大势力；两位以上为顶尖势力。不得仅按“境界高低”忽略控制范围、帝兵、资源与联盟席位。

## 5. 帝星定位

- 帝星是帝落域最强的V级核心古星，是帝院、五会势力、大帝传承与顶尖天骄的高密度交汇地，不等于归一联盟本身。
- 内部五洲沿用既有资料：南淞州（宋王府、万仙阁、古仙神朝等）、西龙州（古佛宗、五色神朝等）、北烟洲（古神族、北海蛟族、万妖阁等）、东华洲（飞仙教、尸谷、灵族支脉、极天妖族等）、中洲（万妖武殿、神时阁、古藏、道一宗、帝院、星族、天机阁、李族等）。
- 出场节奏：卷一仅传闻；卷二使者/传承投影；卷三明确其为帝落域核心；卷四势力影响外部舞台；卷五首次进入；卷六成为长期舞台之一；卷七—八与联盟、帝路共构终局舞台。
- 建议联盟最高议事地设在**帝星中洲的联盟议庭**，但八域各有执法殿、传送中枢与驻地；议庭是会址而非帝星政府，避免帝落域垄断联盟。

## 6. 归一联盟定位

归一联盟是八域共同秩序与最高强者联盟：调停跨域战争、处理跨域犯罪与禁区异常、维护主航道和大型传送、组织跨域军团并参与帝路秩序。它不是普通宗门，也不吞并各域内政。

|层级|既有正式数据|
|---|---|
|外门执法|归一候补为主，少数归一；承担一线跨域执法|
|内门执法|外门满五千年可升，最低归一|
|长老院|50席；五会约30席，龙/灵/冥/神等盟友约10席，无势力散修约10席；最低合一|
|联盟领袖|一万年推选；掌握约半数联盟资源，另半数由五会制衡|
|实力基线|宇宙约230位归一，联盟约160位；龙族约30位；联盟有十余帝兵，多数来自五会|

五会宇宙级定位：李氏族（人）、神武族（妖）、古夜族（人）、帝兽族（妖）、星族（人）。原始资料已确认其种族、对领袖和长老院的主导地位；**尚未给出五会各自核心星、控制星系、帝兵、归一人数和盟友的完整表**，本轮不擅造新答案。建议下一轮从用户原始资料中补录后再定为正式地理配置。

内部矛盾限定为：五会席位竞争；人妖话语权与其他种族的平衡；长老院与领袖的资源制衡；散修归一与大势力归一的代表权；帝星/各域资源和内政干预争议；对长生尊风险的判断分歧。联盟整体仍是可合作的公开秩序力量。

主角路径：卷五获得帝星顶尖势力身份 → 卷六受联盟招揽、进入外门执法/特殊客卿体系 → 卷七获正式宇宙级决策资格 → 卷八联合并反制联盟内部受长生尊影响的局部力量。

## 9. 主线地图阶梯

地方星球 → 完整星球 → 星系 → 星海区 → 其他八域 → 帝星 → 归一联盟 → 帝路。

轮回地点采用“邻近路径”而非抽卡：前世遗留随商路、军团、族地、航道或联盟网络进入下一层；每一次换世至少交付一种新修炼环境、一种新势力关系和一个前世回响。

## 11. 风险检查

- 八域不缩为单一大陆；帝星始终是帝落域V级核心古星。
- 归一联盟是宇宙级组织，拥有八域驻地而非帝星普通宗门。
- 卷三补齐星系、卷四补齐星海区，避免主角长期困在单星。
- 卷五再进入帝星、卷六再完整展示联盟，防止世界观提前膨胀。
- 每世地图升级必须带来境界、敌人、资源、关系与长生尊线索的实际升级，不能只是换景。
- 五会的地理与细项资料不足时保留空位，禁止用无剧情用途的新星球、新势力填充。
