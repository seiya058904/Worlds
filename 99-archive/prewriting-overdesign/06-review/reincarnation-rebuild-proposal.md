# 轮回转生方案重构提案（P0商业方向修正版）

> 历史提案：本轮定点修复已完成后，本文仅保留重构前的决策追踪；不得作为当前状态、章节或设定依据。当前有效状态以 `00-project/status.md` 为准。

## 1. 一句话故事与主角欲望

一个带着地球记忆在玄幻世界长大的少年，死亡后不断在未来的新生命中醒来；他只能带走完整人生记忆，却要在每一世重新修炼、守住新的家人与朋友，最终以最后一世的实力踏上帝路，对抗妄图永远不死的长生尊。

> **我要活好每一世，去看更高的天地，不让这一世留下上一世同样的遗憾。**

## 2. 三个核心卖点

1. **死后不是重置。** 主角换一个未来身份继续活，前世的人、物、选择和错误都会在后世留下意外回响。
2. **记忆是优势，不是战力。** 他能学得更快、避开错误、把握机缘，却不能继承修为、身体、资源或身份，仍要用当世身体一步步变强。
3. **每一世都有新玩法。** 人族成长、宗门炼器、灵族医药、龙族战争责任与帝路争锋各自成篇；家庭、师徒、同伴与日常都是真实人生的一部分。

## 3. 唯一金手指

**主角死亡后会在未来的另一个生命中转生，并完整保留此前所有人生的记忆。**

1. 死亡后进入未来下一世，世界不重置。
2. 保留所有前世完整记忆。
3. 修为、肉身、血脉、法宝、资源、身份和寿元均不能继承。
4. 记得不等于会做；新身体仍须重新修炼、训练和适应。
5. 新世可为不同种族、性别、阶层、家庭和地区。
6. 前世事件成为真实历史；无任务、面板、奖励、抽奖、加点或可选继承。

前五章只让读者理解基础玩法，不解释轮回来源、次数、时间间隔、地球穿越关系或谁控制轮回。

## 4. 开篇1—5章

主角第一世名为**裴照**：地球人穿越后从婴儿在此界长大16年，地球记忆只提供观察、比较和成熟判断；他已把父母、妹妹、黑沙镇当作真正的家。正文不写婴儿成长史。

| 章 | 关键行动 | 读者回报 |
| --- | --- | --- |
| 1 | 成人测试中，裴照本能觉醒“死后会在未来醒来并记得”的轮回能力。当夜地方军寨借兽潮封镇，统领韩烈宣布镇民不得离开。 | 异常、家庭、危机同章出现；敌人具体可记。 |
| 2 | 他从矿道和商队经验判断封镇不是救援，经废弃引水渠先带父母、妹妹和孩子们撤离。 | 成熟判断立刻救人，小胜真实落地。 |
| 3 | 追捕到来，他返回镇中引开搜兵，救出邻家女孩阿禾；把父亲留下的旧铜哨交给妹妹。 | 主动战斗、逃亡、救人和一件可记住遗物。 |
| 4 | 低阶裴照为幸存者争出离城时间，死于实力差距与主动选择；只知军寨为了更大的命令牺牲小镇。 | 第一世有损失、有收获、有遗憾，不解释大阴谋。 |
| 5 | 二十余年后，裴照在16岁人族少年**顾行舟**身上醒来，成为边城小武馆馆主之子。他修正晨练吐纳，避免一名弟子走火；街童吹响旧铜哨，表明阿禾一脉仍在。 | 新身份、记忆即时修炼收益、轻量历史回响，建立当世“保武馆、进学宫”主线。 |

## 5. 第一次正式转生身份

推荐：**顾行舟，16岁人族男性，边城小武馆馆主之子。** 身份比裴照略好但不显赫；武馆因债务、父亲旧伤和竞争武馆压迫而可能失去州府学宫名额。

| 候选 | 优点 | 不选为首转生的原因 |
| --- | --- | --- |
| 顾行舟：武馆学徒/少东家（推荐） | 可立刻修炼、比试、外出、承担家庭危机；前世经验直接改善吐纳、实战与求生。 | 无。 |
| 没落家族旁系少年 | 家族资源竞争清晰。 | “旁系逆袭”常见，首卷容易走向单一打脸。 |
| 小炼器家族学徒/宗门预备弟子 | 技艺成长有差异化。 | 工艺解释较多，首卷战斗与外出兑现偏慢。 |

灵族女孩药摊人生移动至第三段，届时异种族、异性别与自然体系作为成熟读者的新鲜玩法，而非首次理解轮回的障碍。

## 6. 第一卷（1—30章）爽点曲线

| 区间 | 小篇章 | 当世成长兑现 | 回响/长线控制 |
| --- | --- | --- | --- |
| 1—5 | 封镇与首次转生 | 觉醒、主动救人、死亡、顾行舟首次吐纳小胜 | 仅铜哨；不讲帝路。 |
| 6—10 | 武馆晨练与擂台名额 | 纠正发力、修炼入门、父亲认可，出现竞争者许沉 | 无额外查史任务。 |
| 11—18 | 猎场采药与债务 | 外出冒险、获药材/基础武技、改善武馆生活 | 旧经验误判妖兽而受伤，证明不能照搬。 |
| 19—24 | 城中委托与擂台前夜 | 实战破局、同伴/对手建立、取得参赛资格 | 为救同伴错过修炼，首场失利或重伤。 |
| 25—30 | 武馆保名额 | 与许沉一方决胜，保住武馆、获得州府学宫资格、实力地位地图跃迁 | 卷末由铜哨后代带来一句旧话，只埋一条长线。 |

第一卷最强兑现是**当前家庭危机解决与进入更大修炼世界的资格**，不是洗清前世污名或公开历史真相。

## 7. 五段正式人生与八卷工作版

| 人生 | 卷/类型 | 当世主线、生活与关系 | 最强高潮、结束与后世影响 |
| --- | --- | --- | --- |
| 顾行舟 | 卷一；人族边城修炼成长 | 武馆、家庭、同门、猎场与州府学宫资格 | 武馆翻身；其后州府事件中死亡，留下改良吐纳笔记。 |
| 陆闻川 | 卷二—三；宗门炼器/团队冒险 | 师徒课程、器坊订单、同队遗迹、宗门日常 | 修器救队；遗迹坍塌中护同伴而死，留下未完成器胚。 |
| 青绫 | 卷四；灵族医药/自然体系 | 药摊祖孙、学堂朋友、采药节庆、聚落疫病或兽患 | 救聚落、留药方；寿尽或护族地而终，药方在后世被改良。 |
| 烬萝 | 卷五—六；龙族旁支/战争责任 | 祖地课程、旁支亲族、边境委托、统军与守城 | 带旁支守住故土，战争重伤而亡，救下的人在后世留下盟友关系。 |
| 沈昼 | 卷七—八；帝路争锋 | 学宫同伴、当前家人、跨族盟友、禁区试炼与帝路 | 最后一世以真实修为、同伴和行动击败长生尊，决定轮回去向。 |

八卷小篇章工作方向：

1. 卷一：封镇、晨练擂台、猎场、委托、武馆战。
2. 卷二：宗门课程、器坊订单、同队日常、器坊竞争。
3. 卷三：遗迹、节庆、团队磨合、宗门大比与救援。
4. 卷四：药摊、采药、学堂、节庆、聚落兽患。
5. 卷五：龙族祖地、课程、边境、族内竞争。
6. 卷六：势力经营、战友、战场、守城，卷末第一次清晰抬升帝路异常。
7. 卷七：学宫、禁区、旧人后代、帝路预选。
8. 卷八：帝路试炼、盟友选择、长生尊对决、余波。

每卷最终应保持3—5个、每个约5—10章的小篇章；这里是工作定位，不是逐章大纲。

## 8. 四层回报与三层伏笔

| 层级 | 设计规则 |
| --- | --- |
| 章级回报 | 每章至少推进修炼、战斗、资源、信息、关系、日常满足、身份反差或新期待之一。 |
| 小篇章兑现 | 每5—10章让一个当世问题有结果与余波，结果改变资源、关系、位置、风险或线索。 |
| 卷级高潮 | 每30章完成当前人生/身份的一项重大目标，带来实力、地位、地图或关系跃迁。 |
| 跨世大回收 | 每卷最多一至两次，以资源、敌人、情绪、新关系、判断错误或卷末回收之一发挥作用。 |

短伏笔在2—5章兑现，篇章伏笔在5—10章兑现；长线伏笔只指向铜哨与前世人脉、帝路异常、长生尊动向和轮回来源。每卷至少回收旧伏笔一条，但不以搜集证词或档案为任务模板。

## 9. 跨世回响的边界

前世朋友后代、普通物件、修改后的功法、历史人物、变化的势力和误解都可出现，但功能必须轮换：

- 铜哨：情绪与新关系；
- 顾行舟笔记：资源；
- 陆闻川器胚：机缘与误解；
- 青绫药方：判断错误与成长；
- 烬萝救人后果：盟友与卷末大回收。

不得重复使用“官方造假—主角找证据—公开真相”的链条。

## 10. 轮回来源与帝路终局候选

| 候选 | 说明 |
| --- | --- |
| A（推荐） | 帝路长期截留强者灵魂与经验供长生尊延寿；主角来自世界之外，未被完全登记，死亡后反而不断转生到未来。 |
| B | 长生尊早年寻找真正不死法，地球灵魂意外绕开试验，留下无法控制的轮回现象。 |
| C | 帝路损坏正常轮回，主角是第一个未被截留的漏网者。 |

终局可压缩为：**一个活过许多完整人生的人，要击败一个只想让自己永远不死的人。** 沈昼必须靠最后一世修为、当前同伴和实际行动进入帝路；前世只提供经验、知识、人脉后果、遗物、方法、判断和伏笔条件。

## 11. 跨世身份叙事规则

1. 正文以当前名字称呼主角，转生后三章反复锚定“今生身份 + 当前目标”。
2. 内心稳定使用“我”，不另设灵魂代号；自然使用“裴照那一世”“顾行舟这一世”区分。
3. 不是夺舍：当前身体从出生起就是同一灵魂，今生童年记忆与前世记忆叠加。
4. 今生家人是真实家人，不是前世关系的替代品或临时NPC。
5. 转生只重写必要的新限制与当世目标，不重复解释轮回规则。
