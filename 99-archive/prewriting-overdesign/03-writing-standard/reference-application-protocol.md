# 参考研究与素材库正文应用规范

> 适用时点：任何正文起草前、每章起草前、每章完成后、每10章复盘时。该规范是未来开稿后的硬性流程；当前仍不得写正文。

## 0. 原则

参考研究不是“读过即用过”。正文只能在主动核对相关研究、选择适配的抽象机制、写入后检查原创边界后进入下一章。

允许借用：节奏、问题设置、升级的因果链、回报类型、对话功能、关系推进与章节钩子。

绝对禁止：原作人物、身份组合、具体事件、功法法宝、仇敌关系、标志性桥段、固定笑点、句子、段落、独特口头禅及多项具体机制的原样组合。

## 1. 卷前全量复核（每卷正文开始前，必须完成）

逐一阅读并在应用日志勾选：

1. `07-reference-analysis/book-analysis/reference-03.md`：全书结构、节奏阶段与风险。
2. `06-review/reincarnation-reference-adaptation.md`：可迁移/不得迁移边界。
3. `06-review/reference03-commercial-deep-study.md`：升级、战斗、对话、感情与追读链。
4. `07-reference-analysis/payoff-library.md`、`craft-library.md`、`material-library.md`、`anti-patterns.md`：素材、技法和反面问题库。
5. 当前卷对应的 `reincarnation-master-outline.md`、`reincarnation-chapter-outline.md`、`reincarnation-payoff-map.md`、`reincarnation-foreshadowing.md`。

卷前输出一页“本卷应用卡”：本卷主要阅读承诺、3—5种回报轮换、两项对话/关系目标、战斗规则、跨世回响次数、必须避开的重复机制。

## 2. 章前必过卡（每章正文开始前）

每章都必须在 `05-continuity/reference-application-log.md` 新增一行，填写：

| 字段 | 必填内容 |
| --- | --- |
| 章号/所属人生/小篇章 | 与正式章节卡一致。 |
| 本章读者问题 | 下一章/本章需要回答的一个具体问题。 |
| 参考库复核 | 已查看哪些相关条目，而不是泛写“已学习”。 |
| 选用的抽象机制 | 最多3项，如“先给差距后给规则”“资源有用途”“关系中的不同目标”。 |
| 当前世界实现 | 用本书的人、地点、能力和限制重新表达，写清与参考作品的差异。 |
| 本章回报 | 修炼、资源、关系、情绪、探索、战斗、信息或新期待。 |
| 代价/限制 | 当世身体、资源、关系、对手、伤势或选择成本。 |
| 对话目标 | 试探、挑战、交易、关系分歧、情绪收束等其中之一。 |
| 原创边界检查 | 明确无原作人物/事件/句式/桥段组合。 |

没有该行记录，不得起草该章正文。

## 3. 正文中的执行规则

### 升级与打怪

每次升级或战斗按“差距 → 一条可操作规则 → 试错/限制 → 当世条件下的破局 → 现实后果”检查。升级必须同时回答：

1. 新增能做什么？
2. 仍做不到什么？
3. 这次进步改变谁的态度、资源或下一目标？

前世记忆只能给判断、训练方法、经验或路线提示，不能提供前世修为、体质、法宝或自动胜利。

### 爽点与钩子

- 每章至少一个可感知回报；每5—10章一个小篇章结算；每卷至少一个人生、地图、实力、关系或地位跃迁。
- 同一种“被轻视—反制”“获宝—突破”“绝境—反杀”不得连续使用三次；下一次应改为日常、关系、资源、失败、探索或情绪回报。
- 章末必须留下一个具体答案等待：对手、资格、资源、伤势、选择或关系，不用空泛威胁代替。

### 人物对话与感情线

- 一段对话优先完成一个功能：挑战、交易、关系分歧、情绪、敌我价值观。角色必须有自己的目标与拒绝权。
- 每段重点人生至少写一处共同生活细节和一处关系分歧；亲情/伴侣/师友均不能只在临别时承担催泪功能。
- 感情不作为比试奖品、战利品或救主角的工具。最终人生最多一条当世核心感情线；前世感情只作为成熟、遗憾与回响。

## 4. 章后回填（每章完成即执行）

在应用日志补全：实际用了什么、是否兑现读者问题、状态变化、是否与前三章机制重复、是否触及参考相似风险。若发生重复或相似风险，先改正文，再允许写下一章。

## 5. 每10章复盘（强制）

逐项检查：

1. 章级回报是否单一？
2. 每次升级是否有当前身体/资源限制？
3. 战斗有没有真实后果？
4. 日常是否改变关系、技能、资源、情绪、世界认知或下一目标？
5. 对话是否有不同人物目标，而非只为解释？
6. 感情/亲情是否包含生活与分歧？
7. 是否有任何原作具体内容、语言或组合被无意贴近？
8. 下一10章应增加、降低或替换哪类爽点？

复盘结果写入 `05-continuity/reference-application-log.md`；未完成复盘不得开始下一10章。

## 6. 开稿/续写门禁

- 新书开稿前：须完成卷一应用卡、1—10章的章前卡与原创边界预检。
- 每次恢复长期停更后的写作：先阅读最近一次10章复盘、当前人生人物档案、未回收伏笔和当前卷应用卡。
- 任何时候发现“参考机制正在替代本书人物/世界逻辑”，立即停用该机制，回到当前人生的目标、限制、关系和选择。
