# 文风规范

- 目标体验：节奏清晰、情绪直给、冲突有因果、升级有代价、每章有可感知变化。
- 人称与时态：第三人称有限视角，过去时叙述；单章固定一个主 POV，切换必须用场景分隔。
- 叙述距离：贴近主角当下判断；不替读者提前公布主角未知答案。
- 语言：白描为主，关键战斗与情绪点允许短促、具象句；避免连续堆叠形容词、古风套话和夸张感叹。
- 节奏：开篇三章内给出妹妹危机、帝骨代价与第一目标；每 3—5 章完成一个小目标或翻转；每卷结尾改变主角所理解的敌人。
- 战斗：先写目标与空间，再写限制、选择和结果；战斗结果必须留下伤、债、关系或信息变化。
- 信息：用行动、后果、对话中的避让呈现；背景只解释当前冲突必要部分。
- 对话：短、目的明确，人物不替作者说明设定；高压时允许打断、留白和错答。
- 禁止：套用参考文本的句式、专名或桥段；“震惊全场”式旁观者复读；靠主角隐瞒内心制造假悬念。

## 参考03驱动的追读执行规则

- 标题：优先“局势/目标 + 意外代价或反转”的白话信息，不写空泛诗性题；同机制标题连续两次后必须换冲突入口。
- 开章：前 150—300 字交代承接状态和此刻压力；不要从景物铺陈、回忆或解释设定起步。
- 正文推进：每 600—1,000 字至少有一次可感知变化（新阻碍、判断、行动、信息或关系）；不是每次都加战斗。
- 金手指：先展示不能做什么、付什么，再展示能做到什么；能力兑现不得越过世界规则或替代伙伴选择。
- 战斗：一场只围绕一个清晰目标（逃、护、夺证、拖时、封口）；以空间—限制—决策—后果写，不用数值报表堆压迫感。
- 群像：重要配角必须有独立目标、可拒绝的选择与不可逆损失；禁止只为主角喊强或递道具。
- 断章：强断章给新危机/答案/选择，静断章给已付代价或关系余温；连续两章强断章后必须提供可消化的兑现。

## 每章开稿检查

1. POV 当前知道什么、害怕失去什么？
2. 本章即时目标和唯一主阻力是否可在首段看清？
3. 结尾前是否发生不可逆状态变化，而非只延长危机？
4. 爽点是否由代价、证据、选择或协作支撑？
5. 是否新增了与前两章同质的打脸/获宝/升级？若是，删减或变体化。
