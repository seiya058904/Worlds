# 人物弧线

| 人物 | 开场—中点—最低点—最终选择 | 不可逆代价 / 终局状态 |
| --- | --- | --- |
| 顾长安 | 救妹、替人扛账 → 发现帝路把“救命”做成收割 → 想独祭毁骨解决一切 → 公开自身账、只请求众人一息选择 | 第 202 章余三年；毁骨吞回长生印并再付一年，跌回问仙余两年；一年后以余一年寿元入新帝路 |
| 顾青禾 | 被保护的病人 → 拒做钥匙并掌握候选声纹 → 被封阵心仍传出反阵坐标 → 制定退出权、补名计划与自己的生活 | 不再靠顾决定；留守矿城成为补名人 |
| 苏见星 | 中立记录者 → 发现自家祖辈亦涉旧账 → 公开真相导致盟约撕裂 → 将记录分散到万人 | 失部分灵能；建立可复核副本档案 |
| 敖烬 | 守龙族血统 → 看见旁支被主脉当燃料 → 放弃祖地先撤人 → 以失地者身份谈共治 | 失古域家园；成为旁支与各族的新盟约使者 |
| 宁无咎 | 复仇与傀儡控制 → 发现控制也会复制压迫 → 交还控制印、拒绝献城 → 让程序和证言替代私判 | 失傀儡术；守矿城首案石碑 |
| 李观澜 | 秩序优先、相信可控牺牲 → 联盟审讯失败 → 交出阵权而非牺牲他人 → 以无权者身份协调赔偿 | 失正式权柄、重伤；被公开问责后参与重建 |
| 人神尊 | 旧共谋者求自保 → 守退出门换有限信任 → 想自毁逃责 → 活着交出神位与寿元收益 | 无再争帝位资格，等待长期受审 |
| 天神尊 | 用秘密换权 → 抢源账伪造赦免 → 旧债具名反噬 → 交半页受审 | 失权，不洗白；成为制度首个高位被审样本 |
| 长生尊 | 被旧帝路牺牲的无名者 → 把恐惧死亡制度化 → 隐秘性被万人证言撕开 → 以旧账困住 | 被封矿底并百年复核；理解不等于赦免 |
