# 三本参考的融合工作笔记

> 已读取三本原文及用户世界观。只提取高层叙事技术；不复用其专名、人物、句子、关系或标志性桥段。

## 可迁移长处

- 《玄幻：逆命万世，我打爆仙帝》：完整人生的压缩、死亡结算、转世后旧人旧事反噬当前，以及直接的连载目标推进。
- 《完美世界》：用强物象和环境压力建立场景生命力；在成长、亲缘、部族/宗门归属里逐步放大天地。
- 《遮天》：以古物、残碑、错误历史和未知真相牵引求道；让人物在更大世界的边缘先看见一道裂缝。

## 本书融合规则

每一世用“人生目标—修炼/关系节点—不可逆失去—死亡结算—后世后果”组成骨架；每一章用具体事件而非设定解释推进；场景有可见压迫，谜团只给人物当下能摸到的残片。轮回优先，地图逐层扩大，前世后果必须在新一世改变资源、名誉、关系或危险。
