# 硬性限制

> 仅记录用户明确确认、不可擅自违反的要求。

## 必须保留的世界设定

- 用户提供的九大种族、境界序列、归一三阶段、半道/绝巅/帝落/大帝道尊、帝兵道兵、八域、九大禁区、帝路争锋与长生尊相关历史。

## 必须保留的人物设定 / 事件 / 结局条件

- 尚未由用户明确指定。

## 明确禁止的内容

- 不复制参考文本的句子、独特表达、人物、地名、专有设定、情节结构组合或标志性桥段。
- 不模仿在世作者的独特个人文风。

## 题材与受众限制

- 番茄风格的长篇东方玄幻连载；第 3 本参考文本为主要风格参考，前两本为辅助参考。

## 用户最新明确决定

- 主线、人物、书名、结局和其余创作内容由 Codex 自主设计，完成开稿前准备后交由用户审阅。
